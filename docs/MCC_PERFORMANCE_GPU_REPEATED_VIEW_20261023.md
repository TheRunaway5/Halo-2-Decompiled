# Repeated-view ordinary GPU preparation: current-source audit

2026-10-23. Read-only source audit while the parent builds its separately owned candidate. No compiler, profiler, probe, game or benchmark was launched. The following are static operation counts and ownership facts, not measured savings or GPU-default acceptance.

Whole-pose reuse already exists. The frame cache is keyed by full uint32 owner and LOD; its entry additionally compares the actual `RenderModel*`, complete WORLD-node bytes, deferred mode, rounding and MXCSR controls. A compatible deferred hit returns retained local vertices/palette and avoids `model_skin_world_pose` and its arithmetic admission. Strict selected hits also require recorded FP/errno effects already present; diagnostics or incompatible effects rebuild. These are real conditions, not a promise every view hits ([frame cache](../src/rendering/models/model_frame_pose_cache.hpp:9), [entry key/hit](../src/rendering/models/model_world_pose_cache.hpp:88), [deferred provider](../src/gameplay/multiplayer/multiplayer_runtime.cpp:4335)). `model_skin_world_pose` still builds the original inverse-bind/compound palette before its final-kernel admission ([factory](../src/rendering/models/model_pose.cpp:298)). Node construction/history/attachments remain CPU/source work.

The body presentation path also invokes separate `model_skin_world_pose` calls for its full body/held banks before using selected geometry ([runtime](../src/gameplay/multiplayer/multiplayer_runtime.cpp:5862)). That is not evidence those calls are removable: their `RenderModel` can differ from the selected LOD model, CPU overlays/diagnostics/fallbacks consume posed banks, attachments need real nodes, and palette arithmetic has host FP effects. Do not equate this full bank with the source-selected cache by owner alone.

The narrowest falsifiable proposal is **per-prepare referenced-row classification reuse inside `ModelSkinGpu::prepare`**. During its unchanged first full-palette finite scan, compute an integer-only `normal_valid` bit for the first4096 global rows in a zero-initialized64-word uint64 stack array (512bytes). At the original per-influence check, use that bit only after unchanged uint16 bone/owner-extent tests; global indices4096 and above execute the exact old12-component normal scan even in a mixed-size palette. Compute the global index as `std::size_t(record.palette)+bone` without uint32 truncation, and guard bit-array/shift indices. This applies the row-summary idea already installed in the separate full arithmetic predicate ([admission](../include/halo2/model_skin_gpu_admission.hpp:47)); that existing optimization must not be counted again. The service summary needs only row normal validity, not lattice/exponent recomputation.

Required invariants: no heap allocation before complete programming validation; full finite/upper check still rejects unused NaN/Inf first; unused finite subnormals remain allowed; active and interior-zero referenced subnormals reject at their original record/bone stage; trailing-zero bones remain unread; malformed mode/destination/owner extent wins over resource injection; `count=0` and next-job recovery remain unchanged. No FP comparison/arithmetic on rejected inputs; caller SSE/x87/errno state is retained on success and every error. The summary lives for one call and names only the immutable palette span supplied to that call, so it needs no cross-frame owner epoch or new source callback policy.

Start with a source-pinned old/new service-validation differential for exact error strings/order and complete SSE/x87/errno state on normal/refusal/hard-error exits. Exercise global rows0/4095/4096, palette extents4095/4096/4097, base-plus-bone crossing the summary boundary, signed zeros, unused/referenced/interior-zero subnormals, rejected signaling NaNs/Infs, empty/huge valid spans, repeated row references, trailing-zero bones, owner spill and all typed-refusal controls. Existing seams are [service failures](../tests/model_skin_gpu_tests.cpp:144), [ordinal/pose identity](../tests/frame_model_skin_plan_tests.cpp:208), [numeric reference predicate](../tests/model_skin_gpu_admission_tests.cpp:81). Inspect optimized machine code for integer-only classification; then measure process-CPU medians on actual merged frame records and qualify unchanged complete vertex/frame/source receipts. A cheaper inner gate alone cannot establish an FPS improvement.

Sharing the actual GPU result is a larger change. Eligibility must identify full owner generation, exact immutable model/LOD and complete pose/palette bytes with original owner extent, expanded source ordinal, exact local position/basis/binding bits and post-identity mode. View-selected sections/order/duplicates, shader coverage/LOD, material/color/PRT/UV/stipple and draw order remain per destination. The compute shader writes only position/normal/tangent/binormal ([kernel](../shaders/model_skin.comp:32)); a full-`Vertex` copy would overwrite view-specific metadata ([Vertex](../include/halo2/cache.hpp:115)). Reusing one deformation would need an explicit attribute-only scatter plus compute-write/read synchronization and precise allocation/refusal/verification accounting. Pointer/float-byte equality, shared owner alone, or a fixed-frame cache is insufficient. No such result-sharing proposal is admitted by this audit.
