# Owned sound-map metadata and cache startup integration

The production cache library now includes the complete original sound cache CPU constructor. Its registered test composes that constructor with the original sound startup owner and compares the complete retained startup arena and cache allocation buffers at the original platform request. No device success, map-ready byte, cache-read completion or voice admission is supplied to the original execution.

The source implementation and authority are described in [the cache constructor study](MP_SOUND_CACHE_STARTUP_NATIVE_INTEGRATION.md). Root integration adds its `halo2_cache` source and registered `original_sound_cache_startup` test; it does not change the implementation's frozen source. Normal GCC and GCC ASan/UBSan tests pass, including 4,090 ordered constructor writes, complete rounded allocation buffers and actual host memory protection. The composed startup reaches the same original platform boundary. This is not a live launcher playback result.

## Literal constructor callback identities

`OriginalData::load_xbe` now imports the two actual `PUSH imm32` operands from the complete paired cache constructor. It checks the opcode and that each target has mapped executable backing. They remain source identities in allocator records, never native function pointers or successful callback results.

| Operand | Disc update 1.1 instruction / identity | Owned final update instruction / identity |
|---|---|---|
| Delete callback | `21A736` / `21AAF0` | `21F036` / `21F3F0` |
| Busy callback | `21A731` / `21AAB0` | `21F031` / `21F3B0` |

The independent exporter authenticates the paired provider packet `648d78324c1c0863b6fc22116834863583dc3db417861a352cf981ed327462dd` and both complete owned executable hashes before retaining their instruction bytes. Measured and independently repeated exports match. `original_sound_cache_startup_constants` verifies all 16 imported operand bytes across both images and absence of this optional provider for the base executable. The exporter also verifies all 20 instruction bytes. Both registered normal and sanitizer tests pass.

## Complete opaque map data

The existing `SourceTagMetadataStore` can retain explicit resident tag groups without guessing their internal layout. The new sound-map inventory exports complete `matg`, `sncl` and `ugh!` payloads for every map in the authenticated 23-map inventory. Each input map hash and each complete payload extent is checked independently before export. This is an observed inventory, not a default datum-selection rule for map activation.

`owned_sound_map_metadata` reads every payload through both the retained definition and source-address callback. It verifies original datum, group, address, complete extent and every byte, then checks that callbacks retain the actual cache after the facade is destroyed and release it with their last owner. Across 23 maps, the comparison covers 69 complete payloads and 5,244,048 bytes. Normal and GCC ASan/UBSan tests pass. The two independent exports match byte for byte.

The measured and repeated fixtures stay in ignored local analysis directories. Their data comes from owned maps, not compiled native source. The new native code does not embed original map metadata or sound samples in the repository.

## Remaining integration

These providers do not run `126DE0` map activation, publish `ugh!` through the active `matg` owner, obtain current listeners/local players, perform driver effect calls, select a permutation, admit a voice, pin asynchronous cache pages or consume a live reload event. The native SDL packet platform is a separate tested service. Original saved audio settings, live effect state, class fades and original cache lifecycle remain separately owned inputs. The original driver setting cannot be derived from the host device's channel count.

The canonical launcher is unchanged. Canister collision/explosion, live reload playback and grenade throwing remain unresolved in that build. Provider and CPU-owner comparisons establish their stated boundaries; they do not establish all-map audible gameplay parity.
