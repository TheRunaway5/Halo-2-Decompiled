# Native ordinary director reset

The semantic native `157EB0` kernel implements the real cold mode0 reset and all nonmode2 branches. It clears 323 ordered words, resets the global selector and flags, initializes eligible original view records, loads each current interpolation selector, publishes channels in original order and finishes the actual director fields. No replacement camera, private guest stack or virtual CPU is created.

Authenticated table `157FA8` selects normal initialization for modes0/1/4, the actual `246190` initializer for mode2 and no controller initialization for mode3; values above4 also skip that initializer. Cold reset explicitly stores global mode0, so it does not call `246190`. If a real later source read selects mode2, the native kernel throws a typed required-owner error containing actual owner `246190`, record address and view, after retaining every preceding publication. It neither supplies controller success nor calls a lifted implementation.
