## Outer inputs and result ownership

`C57A0` receives unit datum in **EDI** and target in **ESI**. It requires unit header type bit0 and target type mask`1C` for the geometric path. It executes `E0C20` for the actual unit capsule and `FBFA0` for the item point. Capsule height/radius are the `bipd` metadata/state inputs documented in the frozen spatial note, independently of the interaction sphere. The original order is top→item, bottom→item, target-side clipping, then the four side visibility segments, stopping as soon as a visibility cast is clear. [C57A0](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000c57a0.asm), [capsule](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000e0c20.asm), [FBFA0](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000fbfa0.asm).

`16BAC0` receives start pointer in **EAX**, end pointer in **ECX**, one ignored datum in **EDX**, then three stack words: mask, other ignored datum, result pointer. It computes each delta component as original `end-start`, forwards the six arguments to `16B240`, and pops`0C` stack bytes. `16B240(mask, origin*, delta*, ignore0, ignore1, result*)` pops`18` bytes. The report retains exact caller, start/end/delta bits, ignored full datums and outputs. [Segment wrapper](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/0016bac0.asm), [dispatcher](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/0016b240.asm).

All descriptors use root 0, interval[0,1], initial best fraction`7F7FFFFF`, prior leaf/plane`FFFFFFFF`, prior class 0, and intact breakable bits. The current BSP is the actual mapped Lockout block. Its source addresses, raw block strides/magic, descriptor offsets and lower-result layout remain the [frozen raw terrain contract](MP_PICKUP_SPATIAL_RESEARCH.md#raw-terrain-inputoutput-contract); no generic BVH result is supplied.
