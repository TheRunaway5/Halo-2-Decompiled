# Native ordinary terrain outer query

The native `ordinary_terrain_query` now implements the bounded TU1.1
`16B240` ordinary-terrain branch over the existing raw collision kernel. It
imports the original leaf-to-cluster array, forms source locations and the hit
plane/material, applies the original normal offset, and preserves every retreat
iteration. Native primary-channel animation clocks are a separate completed
gate; neither gate establishes complete multiplayer physics or pickups.

## Authority and validation

The independently frozen [fixture export](MP_PICKUP_OUTER_FIXTURES.md) copies
original executable outputs and actual cache records. Its pinned manifest and
all source/payload dependencies are verified by
[differential_terrain_outer.py](../tools/differential_terrain_outer.py).
Expected results are never generated by native collision code.

All four focused normal collision/clock checks pass, as do three focused
address/undefined checks with leak detection. The logs are
`integration/terrain-outer-focused-tests.log` and
`integration/terrain-outer-asan-tests.log`. This is a separate gate after the
105-normal/27-sanitizer animation-clock checkpoint; it is not a newer full-suite
or rendered-sanitizer claim.

The native test matches **1,785 ordinary queries / 1,392 hits**, all **107
normal offsets**, **2,122 retreat iterations**, **2,645 classifier calls**,
**2,364 locator calls**, **three oriented plane calls**, and every **2,313
leaf-cluster / 19 material** import. Two original casts whose masks select
active physics are explicitly excluded. The query test compares only the
source-defined bytes of the 92-byte result, separately checks AL, and preserves
lower hit/traversal/contact state when the outer point/fraction changes.
The independent classifier and locator checks use exact source point bits.

Retreat rows compare step, before/after fraction, before/after point and both
locations. All captured iterations are required: edge399 takes 1,454 and
edge1101 takes 549. The twelve zero clamps, including fraction-zero/location
NONE exits, remain distinct from misses. The richer source instruction-stage
`S` records are retained but are not compared by this native test.

## Implementation scope

[terrain_outer.cpp](../src/terrain_outer.cpp) retains the original separate
float32 operation order. The nonzero-dot retreat division uses the source x87
division followed by a float32 store. Packed-node traversal evaluates z, y, x
products in source order and returns a leaf identity; the locator also imports
its signed cluster and returns that cluster. A lower crossing-plane pointer
is validated independently of the signed surface-plane identity.

The public interface requires explicit segment, mask, active BSP, intact
breakable state and default global material. It admits one ordinary collision
BSP, matching the actual fixture. No guessed point, pose or runtime material
default is embedded. Unsupported active-physics masks/BSP conditions are
rejected. The statically recovered zero-dot fallback exists, but zero-dot,
unordered and additional BSP correction paths have no executed parity claim.

Live candidate enumeration, object bounds/current-node production, inventory
capability/action/attachment, active object/instance winners, Havok motion and
item settling remain integration gates. This module does not replace them with
host collision or rendering poses. See the frozen
[pickup composition contract](MP_PICKUP_NATIVE_CONTRACT.md).

```sh
cmake --build build-multiplayer --target terrain_outer_tests -j 4
python3 tools/differential_terrain_outer.py
ctest --test-dir build-multiplayer -R '^retail_terrain_outer$' --output-on-failure
```

The original map/executable and exported outputs remain in ignored local
storage. The test returns77 when those inputs are absent from a code-only copy.
