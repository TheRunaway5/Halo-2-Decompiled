All75 complete native packet comparisons pass in normal and address/undefined-sanitizer builds. The old neutral initializer/cached delivery interface and two-case tests still pass. Production changes are confined to `include/halo2/player_command.hpp`, `src/player_command.cpp` and `tests/player_command_tests.cpp`; CMake, Unit, Simulation and live rendering are unchanged.

This closes the command-to-control consumer seam. It does not establish natural device input, a source physical-state producer for every live unit, the downstream physical request/animation/pose or a working live animation session.

## Interface and source inputs

The API accepts an already delivered5C command, `SourceCommandCurrentUnit`, and the independently selected target unit's flags at+134. It returns the complete7C packet, updated target flags and actual movement-basis admission. Current-player unit and target unit are separate owners in the original ABI; the API does not silently equate them.

| Input | Original owner/read |
|---|---|
| `current.datum` | Player+2C; NONE skips CCC60/current-unit admission. |
| `object_type` | Object-header+3; original SHL masks count to5 bits before TEST BL,1. |
| `parent` | Current unit+14; movement admission requires NONE. |
| `physical_state` | Current unit+3DC byte; movement admission requires exactly1. |
| `restricted_e5680` | Actual separate E5680/E65A0 result, consumed only after the earlier gates. |
| `forward` | Actual current unit+70/+74/+78, used by151980 and E7B10. |
| `related_object_13c`, `seat` | CCC60 current unit+13C and signed+1FC. |
| `parent_seat_flags` | Actual parent definition seat array (+1CC pointer, B0 stride), bit4. Required only after the first two CCC60 gates. |
| `target_unit_flags134` | Target unit+134, distinct from current-unit admission. |

If the unmeasured positive CCC60 parent-seat transform is admitted, or its required seat flags are absent, the API returns `nullopt` and emits no output. Bit4 set bypasses that source transform; the fixture's ordinary on-foot objects bypass it at the earlier gates. There is no invented successful transform/pose.

The native math preserves original scalar SSE order and zero signs,53-bit x87 length/spill, epsilon `38D1B717`, float reciprocal and double retained reciprocal for the pair cap. Source constants/vector pointees are equal in both images: one `3F800000`, adaptive threshold `.5`, cardinal thresholds `3E99999A/3ECCCCCD`, vertical threshold `3F666666`, default direction `{1,0,0}`, up `{0,0,1}`. `E7D84` compares `.5` against absolute current-forward dot movement: **abs<.5 selects .4**, otherwise .3. The port does not derive these thresholds from native movement.

CPU flags/status/exceptions are outside this output API. The comparison uses masked, nearest FP state FPCW027F/MXCSR1F80. The bounded sine/cosine comparisons pass, including vertical cases; Xbox transcendental hardware parity and every possible angle are not asserted.

## Packet and store order

Original order is aim yaw/pitch → optional CCC60 →151AA0 admission/basis/facing/projection →C8250 default constructor →151C90 packed stores →target+134 bit30 store →C8140. On rejected movement admission, source facing remains the original aim and motion remains the input X/Y with positive-zero Z. Rejection does not discard the command packet.

|7C output| Source |
|---|---|
|+00 dword, +04 word| Original type `06000086`, sequence0. |
|+06..+09| Command+1E four bytes, including slot bytes. |
|+0A/+0C words| Command+22/+24. |
|+10 dword| Command+00 flags. |
|+14..+1C| Source-projected motion12. |
|+20/+24| Command+14/+18 raw scalar words. |
|+28..+30| Source-selected facing12. |
|+34..+3C and +40..+48| Actual aim12, including optional source seat transform when implemented separately. |
|+58..+7B| Original9-dword copy command+34..+57. |
| Other bytes | Literal C8250 constructor zeros/sentinels, with all final overwritten fields retained. |

Command+58 byte is **not part of the9-dword copy**. Nonzero sets target+134 bit30; zero clears it, retaining every other bit. This store occurs before invoking C8140. Caller applies the returned flags before `apply_source_unit_input`; its existing full-prefix comparison is independent.

The fixture schema is pinned in `export.json`: `P id command5c current_datum type parent physical E5680_AL target_flags_before forward12 related13C seat16 target_flags_after control7c 151A20_AL`. `N` records the exact expected row count. All expected output words originate in original captures, including negative/deadzone/facing cases. DE960 deadzone is deliberately later: the1/16 captured packet still contains its nonzero codec-delivered movement, which the source unit phase subsequently zeroes.

Existing two-argument test invocation is preserved. The existing CMake target/library source already includes player_command.cpp; **only add the optional third test argument** `analysis/multiplayer/integration/inventory-source/player-control-native/complete/fixtures.tsv` after the existing neutral/cached fixture. No new target/source entry is needed.

For live integration, Controls axes/look can be an explicitly named host command-input boundary; this API consumes delivered command words and does not recover source device scaling/sign/profile/local-member admission or codec quantization. Actual current unit/basis/parent/physical state/E5680 and target+134 must come from their owning representation. `Body.grounded`, world velocity or actor yaw do not establish those fields. The minimum next stages are owned control delivery through C8140, DE960 deadzone/activity/request construction, the actual physical request/state producer and original animation/channel/pose update; the renderer must then share the current matrices with attachment and collision. Natural local device/readiness scheduling, finite successive frame/clock ownership, positive Havok contacts and continuously updated original physical/current-node state remain open. This kernel alone does not make the existing idle-only renderer animate.
