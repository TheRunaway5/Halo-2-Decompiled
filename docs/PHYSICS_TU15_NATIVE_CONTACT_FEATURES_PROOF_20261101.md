# Native TU1.5 simplex feature retrieval

The native virtual34 feature pipeline passes98 complete physical comparisons
per GCC/Clang and rejects three semantic mutations. The [qualified report](../analysis/physics/native-contact-features-tu15-20261101-qualified/report.json)
and [aggregate](../analysis/physics/native-contact-features-tu15-20261101-qualified/aggregate.json)
retain exact source hashes, commands and cases. No original dependency service
executes inside these native calls. Production World binding remains separate;
complete original caller execution with native features is qualified below.

The semantic kernels implement all245 authenticated sites across `2E5E20`
(37 swept-wrapper sites), `3079C0` (132 SoA sites), `3067D0` (32 box sites),
`3070F0` (21 capsule sites) and `1F6690` (23 polygon sites). They consume actual
shape/feature/count/output DATA. Native code does not accept a GP file,
control-frame image, opcode stream or supplied original result.

The SoA path preserves its four-wide unroll, scalar remainder, each pointer
reread and original coordinate/tag store order. Polygon output follows the
source's descending iteration. Box and capsule paths reread feature IDs after
the vector publication before constructing their tags. The swept wrapper
delegates to the current native child owner, performs the exact packed
displacement and preserves the source x87 rounding of the feature lane.

All seven protected producer entries are exercised at their genuine
`30E930` virtual34 boundaries:49 swept calls and49 polygon calls per compiler.
Cases include actual counts, counts0/2/3/4/-1, four-wide and remainder paths,
box/capsule/SoA geometry and paired signaling/quiet NaNs. Each compiler compares
8,856,498,322 persistent bytes, complete64-byte output packets, FP controls/
status and1,434 strict ordered before/read/write events across5,845 original
instructions. Mutations of the SoA feature tag, polygon vertex and swept
displacement are independently rejected.

The [dependency inventory](../analysis/physics/native-simplex-dependency-inventory-tu15-20261101.json)
uses three hardware-breakpoint groups across all seven producers and three
declared query states. All63 observed parent comparisons match the ordinary
strict results. `2E5E20` and `1F6690` each occur21 times. The reached direct
solver helpers are `30D3F0`12 times and `312620`3 times; the other direct
helpers remain separate unexercised paths.

The [local caller-context audit](../analysis/physics/native-contact-features-caller-context-tu15-20261101-first/report.json)
starts after the actual virtual34 return boundaries `30E970` and `30E988`.
Across all remaining local solver paths, no volatile GP value or XMM lane is
consumed before a fresh definition. Only actual caller values in preserved
EBX/EBP/ESI/EDI and the ordinary ABI stack are retained. This does not prove
all transitive callees, private control-byte observability or a production
native-function binding; it supplies no GP/XMM postimages.

## Complete caller/root return with a native feature call

The [complete-return report](../analysis/physics/native-contact-features-full-return-tu15-20261101-final/report.json)
and [aggregate](../analysis/physics/native-contact-features-full-return-tu15-20261101-final/aggregate.json)
qualify28 complete original root returns per compiler. Execution starts at an
actual `2F8630` entry, continues through the genuine `30E930` caller, selects
native features only at its two genuine virtual34 calls, then executes every
remaining original owner through the actual root continuation `1CCACA`.
All2,530,428,092 persistent bytes per compiler, FP controls/status/empty tags
and preserved root ABI values match. Every persistent heap/contact byte remains
in the comparison; only the preexisting returned-private-stack contract is
excluded. Its observed differences, up to28 bytes, remain in each report.

Each compiler executes142 native feature calls:75 swept and67 polygon.
The cases cover all seven producer entries, unchanged input, a declared -1
query threshold, and two independent volatile-state variations. At76 calls,
the adapter poisons EAX/ECX/EDX, arithmetic flags and every XMM word with
independent values, including signaling-NaN patterns and zero. The rest retain
incoming values. Neither mode consumes original return GP/SIMD images or
serializes feature callee stack/control bytes. Only the native memory/FP
outputs and normal void thiscall RET12 contract are published.

The admissible source calls are `30E96D` returning to `30E970` and `30E985`
returning to `30E988`. Their actual pushed arguments are feature-ID DATA,
count and output; ECX supplies the current shape. A production adapter must
authenticate the source/image/owner and actual return word, pass those typed
values and retained FP/depth to the kernel, publish its FP words, preserve
live x87 and callee-saved GP values, and finish normal RET12 (`ESP += 16`).
Volatile GP/SIMD outputs are undefined by this void seam and need no original
postimages. Unsupported owners or numerical state must remain explicit gates.

The full-return cohort rejects a native polygon-vertex mutation. The earlier
[control-selection run](../analysis/physics/native-contact-features-full-return-tu15-20261101-qualified/report.json)
is retained RED: all56 positive comparisons passed, but removing the sweep
was undetected by the selected actual zero-sweep case. It is not a valid
full-return sweep control. The separate98-case component cohort does reject
its sweep mutation. No failed raw bytes or operands have been waived.

The final complete-return scratch owner is absent after866,516,992 allocated
bytes were removed. No new large artifact is retained. This proves the narrow
native feature boundary with genuine original callers for these cases; it
does not close native `30E930`, the separate full-native `304350` persistent
constructor lifetime, production World wiring, or visible multiplayer.

The primitive full-return probe helpers were retired after the actual
[production-adapter proof](PHYSICS_TU15_NATIVE_CONTACT_FEATURES_HANDOFF_PROOF_20261101.md)
superseded them. Their exact small qualified source snapshots and hashes

the active adapter regression retains the same root and volatile-state gates.
