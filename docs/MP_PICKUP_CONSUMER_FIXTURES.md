# Observed original capsule and pickup visibility consumer fixtures

This separate [exporter](../tools/export_mp_pickup_consumer_fixtures_1_1.py) preserves **207 original `C57A0/E0C20` observations and 1,513 actual consumer casts** from the frozen visibility and retreat reports. It includes exact source capsule roots/bottoms/extents/radii, `FBFA0` item points and marker/contact records, ordered emitted starts/deltas/masks, captured `16BAC0` endpoints, outer result points and final visibility AL. Expected geometry is copied from the reports; it is never reconstructed or generated by native code. The frozen [outer export](MP_PICKUP_OUTER_FIXTURES.md), [visibility suite](MP_PICKUP_VISIBILITY_RESEARCH.md) and [retreat suite](MP_PICKUP_RETREAT_RESEARCH.md) remain unchanged.

The ignored [manifest](../analysis/multiplayer/integration/inventory-source/pickup-consumer-fixtures/manifest.json) pins the complete original dependency/report/listing chain and all payloads. [cases.jsonl](../analysis/multiplayer/integration/inventory-source/pickup-consumer-fixtures/cases.jsonl) has one JSON object per consumer call; [casts.jsonl](../analysis/multiplayer/integration/inventory-source/pickup-consumer-fixtures/casts.jsonl) has one object per emitted cast, keyed by `case_id/ordinal`; [metadata.json](../analysis/multiplayer/integration/inventory-source/pickup-consumer-fixtures/metadata.json) owns actual biped metadata and original XBE constants. Fields ending in `_bits` preserve float32 hexadecimal words; `location8` strings preserve little-endian source bytes. Report suite/call/query indices provide exact provenance. The initial unit constructor provenance is labeled separately from unmeasured current inputs. Original item headers, parents, flags and contact state are captured at each point-producer call. Matching authored/proximity pose records are retained as exact root-bit matches, without inventing a unique pose history.
