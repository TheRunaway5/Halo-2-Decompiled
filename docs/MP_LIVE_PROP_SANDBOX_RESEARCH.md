# Live authored prop collision and destruction

The live native Match now includes actual authored, posed prop collision
triangles in its existing host mover and shooting queries. Normal SMG firing
can deplete a Lockout power module, age its original pending response, deliver
the authored area-damage request and remove its collider. This is a playable
native geometry integration. It does not claim a Havok solver, movable rigid
bodies, Xbox reciprocal parity or complete explosion particle rendering.

[later-image correspondence](MP_SANDBOX_LATER_UPDATE_SOURCE_RESEARCH.md) and
[source-created power-module contact schedule](MP_POWER_MODULE_CONTACT_SCHEDULE_RESEARCH.md).

damageE72B05B6 and marker04000DE9 for both separate requests. These words are
imported from owned cache bytes, not hardcoded generic barrel tuning.

[oracle_mp_power_module_death_1_1.py](../tools/oracle_mp_power_module_death_1_1.py)
starts with the unchanged original allocated canister and verifies its complete

time, contact, pose or success. Original section pending48 ages through

The original report and every instruction file independently repeat byte for

`cc2475ab1311310587fa83f358c791d5b036b2e5e9bbafe20beac583dfa42d19`.
The [fixture exporter](../tools/export_mp_power_module_death_fixture.py) uses

## Live ownership

[PropSandbox](../include/halo2/prop_sandbox.hpp) retains full Scene generation,
authored placement/definition, normalized vitality, source damage owner and
section damage/pending/destroyed fields. The importer reads actual constructor-
admitted type11 definitions, bind-node hierarchy, collision permutations and
surfaces, model damage info/sections/responses and both marker groups.
An animated idle definition is unavailable to this initial bind-pose collider;
it is not assigned an invented current animation pose.

The live combined CollisionWorld contains BSP triangles followed by actual
posed prop triangles. Prop shooting uses the existing original1EFF40 posed
target traversal and source lower-mask conversion. Prop removal deactivates
the collider before Scene disposal and retains the original attribution through
the delayed request. The existing host triangle mover provides blocking;
contact solving, dynamic canister motion and pushing are not implemented by
this integration. No AABB or generic sphere replaces the authored prop mesh.

The ordinary health/shield path composes existing native damage kernels with
actual damage groups/materials. D8AE0 attenuation uses jpt!+0/+4; D8590 core
visibility preserves cast masks04A08C2D/14A08C2D, side-vector construction,
four ray pairs and each corrected endpoint. The native query backend supplies
current capsule/posed-triangle nearest points and BSP/prop/unit obstruction.
That backend is explicit host geometry, not original185380/Havok point-shape
or16B240 outer-query parity. Native enumeration is Units then Props, rather
than an asserted equivalent original64-entry unsorted registry walk.

Area import retains literal +58/+64/+68 and uses D8280's max(+4,+58,+68)
candidate radius. The independent acceleration/camouflage side effects remain
unavailable. Nonzero acceleration inputs do not suppress the ordinary health
leaf or enlarge its +0/+4 falloff. Actual frag/plasma jpt! imports are tested
separately with query radii4.5/3.5 and retained +64 values10/8.

## Native LAN lifetime and effect request

Persistent PropRemoval records retain full Scene handle, authored placement,
definition, and the **actual emitted** effect datum/position/forward plus the
completed native event tick. The requests are copied from PropSandboxEvent
before disposal; clients do not infer the response from a later definition.
Native protocol22 carries the full bank, which survives lost snapshots and
late joining. Complete batch validation precedes mutation. Exact generations
are removed idempotently, preventing remote ghost colliders. Dynamic prop
transforms/health and prop recreation are not replicated by this tombstone bank.
Root owns client effect/audio baseline consumption so old blasts are not
replayed on join.

## Validation and archive

The fresh production-linked test covers fourteen actual modules,840 triangles,
552 posed casts and338 blocked host moves. Public Match controls and SMG
projectiles damage, delay, blast and remove a real module in57 ticks; the blast
damages the nearby shooter and retains source attribution. The supplied shooter
vantage uses the public debug teleport/noclip API and is not claimed as original
device/spawn provenance. UDP late join, repeat removal, exact collider removal
and atomic forged-definition rejection pass. Both supported1.1 and authenticated
1.5 data providers pass this bounded native test; static correspondence does
not promote the1.1 original death execution into a1.5 execution claim.

All21 real maps import, construct and step:390 retained props and15132 posed
triangles. Normal and actual ASan/UBSan executions pass. The archive under
`analysis/multiplayer/sandbox-source/live-prop/frozen/` retains copied source,
fresh binaries/logs, original report/instruction repeats, fixture and audit.
Shared current source may evolve independently; the archive snapshots do not.
