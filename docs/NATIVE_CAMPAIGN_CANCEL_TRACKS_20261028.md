# Campaign track-conflict closure, TU1.5

`native_campaign_ai_cancel_tracks_tu15` implements all 103 original `275610`
sites, complete `2755B0` active-track traversal (28), complete `274F40` object
property lookup (31), and the actual non-mode2 `217310` policy profile. It
uses the already proved semantic `16EA60` and `C1E90` shared helpers. The
qualified composition covers 231 original sites. Six policy instructions
that call/consume the unresolved mode2 `160A60` callback remain explicitly
unqualified; this is not a whole generic `217310` or campaign readiness claim.

The public API and implementation are
`native_campaign_ai_cancel_tracks_tu15.hpp/.cpp`.
`cmake/CampaignNativeAiCancelTracks.cmake` compiles the production source into
`halo2_physics_world_runtime` and links the existing single shared pool/bit
helper library. There is no virtual CPU, generated fallback, binary execution,
supplied policy result, reconstructed private stack or invented pool owner.

The implementation retains actual track status1/2 checks and exclusions,
next-link reads before status/owner checks, captured pool ownership with lazy
rows-pointer reads, full salted group identity, exact policy-class filtering,
and fresh object/property/track reads. The group scan reads the real capacity
on exhaustion even though only the private iterator uses that value. Policy
class reads the real `4F3218` mode and `5020C4+A4` bitset. Early sentinels and
non2 modes follow the original; mode2 fails explicitly pending its actual
native game-engine owner. No policy success/absence value is manufactured.

The original inactive path loads an uninitialized private local as iterator
owner, then returns if the second enable read is also off. The native version
preserves the stable inactive result and exact enable reads. An off-to-on
transition requires that unavailable owner and fails explicitly. It does not
reinterpret stack garbage as a native input. Ordinary active scans preserve
all enable rereads, including an on-to-off early exit. Both unavailable
boundaries have separate negative admission checks and never count as original
parity coverage.

The unchanged physical-i386 original proof uses owned TU1.5 image SHA-256
`21b207e7efdacaf6124a0822837f8be570766a42505057f7fd2d2ba8f409c4fd`.
GCC and Clang ASan/UBSan compare 73 original cases, 8,048 callee instructions,
1,426 ordered mutable reads, zero engine-memory stores, every qualified
instruction site, retained banks, functional results, preserved original
GPR/stack/SIMD/occupied80-bit x87 contracts and FP controls/status. Native
integer calls also preserve the host FP environment. There are no patched
instructions, original register/state edits, supplied returns or resumed
unknown callees.

One case enters at the real `275770` owner, executes 42 unchanged instructions
through its actual `275949 -> 275610` call, captures real property, actor and
group arguments, and returns naturally at `27594E`. Its legitimate NONE-team
branch reaches this call before unclosed owners. It authenticates this caller

Eight semantic mutants are rejected: admitting status3, inverting actor
exclusion, inverting policy bits, changing the team bound, comparing only a
group slot index, omitting policy-class filtering, propagating the original
actor exclusion into the candidate check, and omitting the capacity read.
The wrong-salt self-group case makes the full-datum distinction observable.
Mapped finite lists, real non2 modes and the stated enable profile are covered;
unmapped faults, dead scratch state, unmasked FP traps and unresolved branches
are not claimed.
