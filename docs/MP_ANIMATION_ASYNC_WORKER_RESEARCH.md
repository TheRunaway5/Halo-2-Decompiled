## File routing and request ABI

Complete `19D8C0` receives location in ECX and six stack arguments `(size,buffer,optional_bytes_output,done,category,priority)`. The high two location bits select current/mainmenu/shared/single-player-shared. The low thirty bits are the file offset. The current token is `[55F798 + [5627B0]*804]`, mainmenu `[5607A0]`, shared `[55F798]`, and single-player shared `[55FF9C]`. The adapter requires those actual file-bank bindings as inputs; their original opening lifecycle is not inferred from image zeros or from an imported Cache.

`1A4870` forms ten words: file, buffer, size, offset, optional cumulative-output address, then five source-proved zeros. It increments requests-added at `4E9EC0`, clears the actual done byte, leases through `121FD0`, copies all ten words, stores done/priority/callback/category in that order, and publishes through `1220E0`. Counter, current-node, bank and synchronization alias addresses are explicit selected-image/runtime inputs.
