# TU1.5 live contrail integration and multiplayer evidence

English retail TU1.5 remains the only physics target. This closes a concrete
multiplayer presentation gap; the complete player, vehicle and object physics
goal remains active.

The authority already ran the original contrail birth, point, aging and
retirement owners. Clients received neither those retained inputs nor their
original geometry path. The runtime additionally nested contrails under the
cached-decal authority path. Actual retained trail and point records now travel
through bounded native LAN snapshots, and both authority and clients run the
same complete original42CE0 geometry callback. There are no supplied trail
positions, colors, widths, contacts, impulses or solved physics results.

The sparse snapshot retains the actual pools, occupancy maps, active rows,
definition descriptors/payloads, bitmap metadata, required owner color records
and the original mutable pointer cells consumed by42FDD/4329F. Uncovered reads
may use only immutable authenticated XBE data; missing mutable inputs and writes
fail. Inputs are limited to2 MiB and32,768 sorted, nonoverlapping slices. Native
transport versions advance to81 in the owned cut and86 in the concurrent root.
This is the port's native LAN protocol, not retail Xbox System Link wire parity.

The acceptance executable previously compiled shared multiplayer_runtime.cpp
without the normal executable's contrail/decal feature definitions. Those
features are now enabled by the same CMake owners. v421–v423 red results remain
retained. Read-only source stores in v423 showed17 successful trail allocations
and actual two-point human trails reaching clients, correcting the earlier
inference from a narrower pre-birth capture. No physics change was needed.

Newborn strips can have zero color and width. v426 therefore requires an actual
submitted triangle with nonzero area and alpha, rather than accepting a draw
count. The callback also exports actual submitted vertices, constants, sampler,
combiner, clip bounds, source tick and frame index for independent inspection.
