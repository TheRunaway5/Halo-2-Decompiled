# Retained unit constructor tail

The native module now implements complete direct owners `110A20`, `116680`
and `110BF0`, with the pure reset/node/name/duration bodies they need. Fourteen
actual source calls match complete retained buffers, five ordered lower
callback packets and 246 direct stores. Normal and sanitizer comparisons also
pass with production Cache-owned metadata and constants imported from either
verified update image. This completes a constructor-tail slice. It does not
yet provide a native fully constructed unit or make Q throw a grenade.

The new module is [unit_constructor_tail.hpp](../include/halo2/unit_constructor_tail.hpp)
and [unit_constructor_tail.cpp](../src/unit_constructor_tail.cpp); its fixture
consumer is [unit_constructor_tail_tests.cpp](../tests/unit_constructor_tail_tests.cpp).
The ignored evidence is
`analysis/multiplayer/integration/spawn-source/unit-constructor-tail`.
`REPRODUCE.md`, `manifest.json` and the read-only audit in that directory give
commands, precise dependencies and immutable hashes. Assets and full source
fixture payloads remain external to tracked code.

## Complete direct owners

`110A20` calls complete `110800`, clears only its listed extension fields,
looks up the two authored node names through complete `16F510`, resets
manager class/weapon and runs complete `1100E0`, `10F380` and `115030`.
`110800` preserves all unmentioned bytes while initializing three subchannels
and the seven/three packed lookup slots. The native store observer retains
instruction identity, absolute unit offset, width, prior and written bits,
including overlapping writes. No blanket component reset replaces them.

`16F510` uses signed count at model `+78`, pointer `+7C` and `5Ch` records.
The actual `masterchief_mp` model (`E9F3086E`, 700 bytes) forwards its
33-node bank at `802AE1AC` into the full `masterchief` model payload
(`E9060781`, `802ADBE8`, 4,532 bytes). A same-tag-only reader would reject
valid original data. Production `SourceTagMetadataStore` resolves that span
through unique ownership of the explicitly imported `bipd/hlmt/udlg` groups.
No copied node defaults or host pointer rebasing are used.

`1100E0` and `10F380` execute complete `1E0AA0` flat animation-name lookup.
It searches root records (`+2C/+30`, stride `6Ch`) then the actual root
inheritance bank (`+4C/+50`, stride `20h`, reference `+4`). Packed low16 is
the inheritance index (`FFFF` for root); high16 is the definition index.
A found row must execute the required complete `1E13C0` resource owner
before storing its result. Missing inherited reference ends the original
search. All three actual constructor requests (`0800004D`, `08000145`,
`0C00024D`) naturally produce `FFFFFFFF` from genuine banks. No successful
resource callback or successful found-row case is supplied by this freeze.
Direct packed-output fixtures retain the literal four prior bytes; private
callee scratch has no source-defined prior value and is not read natively.

`116680` copies the model's default `+90` reference and `+A0` name, walks
`+50/+54` variants at stride `38h`, applies matching or first eligible
fallback references and their tag `+14`, and preserves component `+4`
unless that reference branch runs. Actual default `+90=E96A07E5` is the
`udlg` tag `sound\\dialog\\combat\\masterchief`; its `+14` is zero. The sole
actual variant has name `07000001`, override `+2C=0`, and reference
`+34=FFFFFFFF`. The caller variant zero therefore preserves the actual
component `+4`; no fabricated dialogue value is installed.

**Correction to earlier immutable prose:** the prior constructor document's
description of `116680` as a collision/variant callback was an incorrect
interpretation. Actual references here are UDLG dialogue metadata. The prior
instruction listings, source outputs and direct constructor implementation
are preserved; this evidence corrects that label only.

`110BF0` preserves the original activity-equivalence flags, optional player
transition gate, default selection, mode/activity/forced change decisions,
subchannel rebind, availability bit, blend duration, conditional transition
and final action-cache order. Only selected AL and availability AL are
consumed. Complete `114F70` returns raw duration bits; the original SSE
comparison selects the literal minimum on equality or unordered comparison.
The native module performs no duration arithmetic and manufactures no clock
or rounding rule. Its real constructor case returns AL1, obtains availability
AL0, takes the imported normal blend, and invokes the transition/cache owners.

Production `SourceTagMetadataStore::providers().address/read` supplies
generic tag metadata; `UnitAnimationMetadataStore::graph_memory()` supplies
owned `jmad` data. `OriginalData::unit_constructor_tail_constants` imports
one/zero plus the following literal operands. Base-image support remains
unverified and absent.

|---|---:|---:|

| Normal blend word | `44C6B4` | `450170` |

The independent packet is `original-data-owned.json`, SHA
`e25b3c968c9fe7bf758ddd87cc58e0edf91227e219383025938c537de0bec2b4`.
No tuning payload is hardcoded in native source. Runtime `517FE8` is a
separate required provider, read only when unit `+13C != NONE`. That branch
is unexecuted in this actual nonlocal constructor case and has no default.

`UnitConstructorTailServices::invoke` receives a retained `90h` manager span
and the exact defined packet below. Undefined guest scratch registers are
not reconstructed as native state. The packet keeps full unit identity.

| Required owner | Defined original conduit | Native packet |
|---|---|---|
| `1D0A60` | ECX manager, EAX activity | EAX plus stack mode/class/weapon/flags/`3F` |
| `114F00` | EAX unit | EAX, no arguments |
| `1CFA90` | ESI manager | retained manager, no arguments; consume AL |
| `BB240` | ESI unit, stack duration | full unit plus duration bits; ignore return |
| `114BD0` | stack unit | unit argument; ignore return |

The five native test callbacks compare complete original entry state, apply
complete unchanged-source output and provide only its recorded AL where
defined. They are differential services, not native implementations of the
lower owners. The `1E0AA0` resource service similarly requires a real owner;
none is called in the three observed not-found cases.

Host bounds errors throw for missing/truncated backing, escaped address
arithmetic and unsupported signed-index wrapping. Those are host safety
limits, not invented source return gates. Normal signed counts/widths/store
order are preserved. The tests include absent-owner/backing checks using
actual fixture records, not manufactured unit contents.

## Validation and next live gate

Two independent source executions, static listings, u5 full-body mapping,
literal operands and native fixture exports repeat exactly. Four isolated
CMake comparisons (literal, Cache, Cache+1.1 operands, Cache+u5 operands)
pass normally and under GCC ASan/UBSan. Clang ASan/UBSan passes the complete
isolated native buffer/store comparison. Three top-level production CTests
are registered; this freeze does not claim a full top-level runtime rebuild.
Observed linked archives are copied and pinned independently of later live
build changes; it does not claim every archive member was rebuilt from the
observed include snapshot. Initial host observer/compiler/path mistakes are
retained as drafts and are not guest faults.

To connect existing `C52C0` services, dispatch its required invocation packet
to `initialize_source_unit_extension` (`110A20`, stack unit),
`initialize_source_unit_variant_metadata` (`116680`, EAX unit/stack variant),
or `bind_source_unit_activity` (`110BF0`, EAX flags and seven actual stack
operands). All three still require genuine retained body/component storage.
Do not install the measured final body or fixed offsets into typed `Unit`.

The shortest remaining lower construction frontier is
`114F00→1CEC20`, `1CFA90→1DF670`, transition `BB240`, and
`114BD0→1CF4C0/1CFB90/115AF0`. `1DF670` includes a substantial original
graph-family/resource sweep; a default availability result is not acceptable.
Selection also retains the prior `1D0790/1D06C0`, root-transform and resource
lifetime obligations. The full native `B8A30` body producer and type-store
order are not supplied by this module. These boundaries prevent claiming a
fully constructed live action owner or a completed Q throw. The existing
grenade begin/release/projectile/effect/backend/authority boundaries remain
unchanged. No shared Unit, Simulation, runtime, shader or release is edited.
