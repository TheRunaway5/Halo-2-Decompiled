## Admission, stores and exact immutable fields

`D6660` reads its type pointer at `46FAD0 + type*4` (`474B90` in u5) before admission. Source has no type bounds guard; a host bounds rejection must remain explicit. Initial admission is placement flags`+4` bit6 clear. For type6/game_type2 only, games word`+5A` other than0/7F and engine1/2/3/4/7/8/9 **replace** that decision with game bits0..6. Engines5/6 and the default route preserve it. The reached options pointer cell is mutable `4EDF18` (`4F3218`); its executable zero bytes are not initialized/current game options. [D6660 entry/game branches](../analysis/damage-shields-goal-20261011/overlay-pass/registration/scenario-request/paired-complete/instructions/000d6660-old.asm).

After admission and a nonnull type pointer, palette index`word[placement]` equalFFFF rejects. Other negative signed16 values reject through the clamp/equality path. For a nonnegative index, source computes **wrapping DWORD** `palette.count-1`, compares it as signed32 to the sign-extended index, then requires the selected clamp candidate equal the index. Preserve `DEC`/`JG`/equality semantics rather than an unsigned bounds test or signed-overflow C++ subtraction; malformed count`80000000` wraps to`7FFFFFFF`. The entry address is `palette.pointer + index*28`; definition is its DWORD`+4`. Early rejection writes no caller request. DefinitionNONE skips initialization but reaches the suffix stores described below. [D66F4–D673B](../analysis/damage-shields-goal-20261011/overlay-pass/registration/scenario-request/paired-complete/instructions/000d6660-old.asm).

For a real definition, source calls B8820 with literal ownerNONE/location0, copies position`+8→request+1C`, selects scale`→+58`, computes forward/up`→+28/+34` and writes policy mode low byte`→+14`. Mask`847` admits types0/1/2/6/11 to the extension check: **unsigned** type-record WORD`+0E>=4C` then copies variant`placement+34→request+C`, color mask`+38→+74` and four packed colors`+3C..48→float3s +78/+84/+90/+9C`. The independent full type-record words are below; FFFF in types4/5 does not admit color access because the mask excludes them. ## Floating-point contract and reusable provider limits

At D675B, `COMISS scale,+0; JBE fallback` retains only an ordered positive operand, including positive infinity. Signed zeros, negative values and masked unordered comparisons select the exact one operand. ZF/PF/CF are respectively111 for unordered,000 for greater,001 for less,100 for equal; COMISS signals invalid for either NaN class, and unmasked exceptions prevent its flags update. Denormal behavior also needs actual supported MXCSR controls. The existing `source_object_construction_positive_scalar` models the comparison's MXCSR status/mask path and can be reused; source has no intervening rounding operation. DAZ is an architecture feature requiring processor support, not an assumed accepted Xbox mode. [Original comparison/store order](../analysis/damage-shields-goal-20261011/overlay-pass/registration/scenario-request/paired-complete/instructions/000d6660-old.asm), [native helper](../src/object_construction.cpp#L48), [Intel COMISS, pp3-201/202](https://cdrdv2-public.intel.com/929353/253666-093-sdm-vol-2a.pdf#page=319), [Intel MXCSR/DAZ, §10.2.3](https://cdrdv2-public.intel.com/929351/253665-093-sdm-vol-1.pdf).

`133320` extracts `(packed>>16)&FF`, `(packed>>8)&FF`, `packed&FF`, ignoring alpha. Each DWORD integer goes through `FILD`, `FMUL m32fp` using raw`8180803b`, then `FSTP m32fp`, in R/G/B store order. Each JGE consumes its preceding integer TEST; intervening x87 instructions do not replace EFLAGS, so every unsigned-correction FADD is unreachable after the byte mask. It is not decimal division or a normalization operation. [Complete31 instructions](../analysis/damage-shields-goal-20261011/overlay-pass/registration/scenario-request/paired-complete/instructions/00133320-old.asm).

For a standalone color kernel, own or explicitly constrain the **x87 control word, exception status, TOP/tag/stack state**, separately from MXCSR. FILD requires room for one temporary stack value and converts these integers exactly; successful channels have net zero depth. FMUL follows x87 precision/rounding control; FSTP rounds to binary32 and pops. A precision exception can therefore be encountered at a different instruction under a different precision control, even where masked final binary32 results agree. Pending/unmasked exceptions and invalid stack state cannot be replaced with a successful return. The source leaf changes neither control word nor exception masks and does not clear status; a value-only host multiply proves no x87 status/stack equivalence. [Intel FILD p3-342, FMUL p3-360, FSTP p3-386](https://cdrdv2-public.intel.com/929353/253666-093-sdm-vol-2a.pdf#page=460), [Intel x87 control/status/stack, §8.1](https://cdrdv2-public.intel.com/929351/253665-093-sdm-vol-1.pdf). The retrieved PDFs/text and SHA-256 hashes are retained in the manifest; these architecture references explain instruction semantics, not game admission or a retail caller's FP configuration.

`11F680` copies matrix`+4/+8/+C` into forward and `+1C/+20/+24` into up after complete143450. Existing `source_euler_basis` is reusable for its recorded finite nearest domain: original fixture configuration is x87CW027F/MXCSR1F80, and actual Lockout authored angles are among the fixtures. It does not expose source x87 status/stack, exact FSIN/FCOS edge behavior outside that domain, or arbitrary FP controls. Request binding must keep that limit visible, validate its admitted controls/domain, and propagate unavailable Euler handling as an incomplete prefix. [Wrapper](../analysis/damage-shields-goal-20261011/overlay-pass/registration/scenario-request/paired-complete/instructions/0011f680-old.asm), [whole matrix body](../analysis/damage-shields-goal-20261011/overlay-pass/registration/scenario-request/paired-complete/instructions/00143450-old.asm), [existing native Euler and evidence boundary](source-euler.md), [fixture provenance](../tests/fixtures/retail_source_euler.provenance.json).
