# Live object-node instruction protocol

The shared object-node admission guard now revalidates the actual instruction
callable, exact cursor owner, executor, position, literal policy and three
current service sites. It refuses a cleared callable when State still carries
its cached cursor or literal witness. Trace and observation-only store checks
remain live. The existing typed algorithms, original retained bodies,
dispatchers and their full-body authentication pins are unchanged.

The preserved pre-fix probe constructs real `WorldState` instances and calls
the actual `ADCD0` bridge. Clearing the instruction callback after construction
incorrectly admitted native execution and advanced a cursor that the retained
body left untouched. Rebinding to a different actual callable lost twenty-one
retained callback deliveries. Both complete-return comparisons now agree with
the genuine retained path. Two independently compiled guard mutations recreate
those defects and fail the repaired test with GCC and Clang sanitizers.

Registered sanitizer and optimized Release gates each pass all four tests.
Thirteen after-construction policy changes are exercised through each of
`BF0C0`, `BFB90`, `B8780`, `B87B0` and `ADCD0`, plus the actual prediction-owner
dispatcher: seventy-eight checks per configuration. Each bridge must leave
GP/flags/XMM, x87 controls/status and live 80-bit values, cursor, memory and
observers untouched before selecting fallback. The complete pinned retained
body then executes its real first callback or attempts its real first memory
access. Its resulting state and access counts must match direct retained
execution. These checks do more than inspect an admission Boolean.

All existing hardware, normal/reference, source-copy and retained-prefix
checks pass unchanged: forty-eight parent hardware cases covering all 394
sites, seventy-two animation cases and 288 prediction cases covering all
eleven sites, with the original genuine child boundaries preserved. This
repair adds no whole-fallback continuation, arbitrary-provider, scheduler or
physical page-fault qualification. All owned build trees, binaries and input
banks were removed. The bounded receipt is
`build/test-results/native-object-node-live-admission-closure-20261109/report.json`.
This repair is later than immutable catalog R19.
