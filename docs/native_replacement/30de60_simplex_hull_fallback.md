# Actual 30DE60 simplex hull fallback

The actual 725-site routine is World `run_30a370` in the selected TU1.5
mapping. Its complete source body SHA-256 is
`08aea2d6c59de447d6dcebd6c3bc4182e5b47b25da1d1b8d28e20d1d7503abf7`.
The initial 98 sites now have a private typed seed stage. It builds
the actual paired rows according to both signed counts, publishes all
authored stack stores, then passes six real formals and the actual
return word to `314710`. That caller runs genuine `313BB0` and its
descendants rather than supplying an output.

seed sites, 10,582 complete pre-I/O packets across the three owners,

removed. Nothing is bound by default.

Production admission stays open. In both sanitizer builds, a genuine
memory callback can replace the instruction callback during the first

instruction, `30DE61`, and restores its modified saved SI; the private
retained view does not visit that pure PC. This is an explicit
counterexample to treating the backed normal/failure cases as an
arbitrary provider contract. See
`build/test-results/native-simplex-hull-policy-witness-20261111/{clang,gcc}-r1.json`.
