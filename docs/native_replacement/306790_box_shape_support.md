# Box support (`306790`)

The retained-source qualification assumes backed Memory providers preserve
caller GP/XMM and instruction policy during each access. The cursor's
`observation_only_stores` promise applies to the store observer, not Memory.
Entry admission does not separately certify Memory or resume a retained suffix
after a Memory-driven policy change. Arbitrary Memory GP/XMM feedback and
instruction-policy revocation therefore remain outside the immutable receipts.
Host-FP isolation does not establish those additional contracts.

The shared DATA kernel selects each extent lane's sign by XOR with the
direction's masked sign bits, including the fourth payload lane. The three XYZ
signs form the low feature bits. This operation has no floating-point arithmetic
or comparison. Its raw adapter preserves all19 actual Primary sites, the initial
extent output, late sign/direction-content reads, final feature tag, saved words
and RET8. Both vector stores use this source's eight-plus-eight provider events.

sites,1,408 full pre-I/O GP/flags/XMM/FP/live80 packets,400 atomic-provider raw stopped
read/write/observer prefixes,16 hostile-FP cases and16 backed caller-argument
feedback cases. Direction/output, extent/output and saved-frame aliases are
backed. Four compiled mutants are rejected: missing sign selection, reversed
feature bits, omitted fourth-lane payload and eager direction contents before
the first output store. The comparison SHA is
`323284903e97e9bc957e073c4845a521d66885329e81e50c12bc4ae352d7302d`.
