# TU1.5 296180 packed quaternion decoder

The three authenticated TU1.5 owners now have a native DATA prefix: Primary,
AI-frame and ModelRender. Their exact retained bodies, complete selected
resolvers, numeric dispatchers, LiveState classes and four MMX/estimate helpers
remain authenticated. The corrected installed cohort passed all six registered
checks plus independent Clang hardware, policy, public and source-route gates.

The shared kernel reads four signed codec words and normalizes their converted
quaternion. The raw view preserves the source's `(x*x+z*z)+(y*y+w*w)` grouping,
full XMM2 upper pair, four real reciprocal-square-root service calls, authored
EMMS, lazy global/spill reads, flags and return access. The frontend value view
shares those DATA operations while retaining the existing explicit seed and
default `1/sqrt(norm)` policy, zero-input errors and invalid-seed validation.
This does not establish a separate older-image codec owner.

The raw frame uses the integer FP ownership scope. Incoming dense x87 values or
all eight opaque MMX aliases remain source-owned until the authored MMX/EMMS
interval. The implementation does not clear `active_mmx` to satisfy admission.
Real EMMS empties the source file and resets TOP before reciprocal callbacks.
The dense RawScope contract and common State/FpScope are unchanged.

Reciprocal callbacks can revoke or replace instruction policy. The four
remaining sites DE/E1/E4/E7 revalidate the current callable through
`State::instruction_literal`. MULPS consumes live returned XMM1/XMM0. The output
address and complete 16-byte payload are captured after E1 delivery and remain
captured across the two retained eight-byte stores. The final ADD and RET use
live state after their actual callback boundaries.

The source-owner guard requires TU1.5, a real reciprocal owner, the exact live
three-site instruction protocol or genuinely empty services, supported FP
ownership, and matching cached/current cursor witnesses. Cleared, rebound,
foreign-thread, traced, malformed and unsupported contexts retain the old body.
This childless owner does not call or certify an arbitrary required-owner
provider. `HALO2_REFERENCE_PACKED_ROTATION` selects its real retained body.

invalidated final source stability. The later stable receipt above replaces
that acceptance. Initial route fixture compilation failures and earlier
source-drift diagnostics also remain retained; their scratch trees were removed.
The first installed six-test cohort passed hardware SAN/Release, returned policy
and public value, but its routes/generation fixtures assumed that the native
include remained first after owning-wrapper preprocessing. The correction
restores only the exact single native include to its original position and
requires every remaining source byte to reconstruct. Complete body/context and
helper pins were preserved. The original failed cohort remains in
`native-packed-rotation-official-20261110`; the corrected final receipt above
passed all six tests on one immutable source snapshot.

The physical proof preserves native MOVAPS alignment behavior and saved RF
fault context. The retained source writer uses two eight-byte events. Whole
vector normal/completed-observer projections are measured separately from
second-half partial-write or physical vector atomicity, which remain open.
Intermediate MMX instruction callbacks, arbitrary earlier Memory/Before policy
or ABI mutation, unmasked FP, asynchronous signals/MMIO, other images and an
engine-wide native-only claim are outside these receipts. The common outer
FpScope host condition-bit limitation remains a separate integration item.
