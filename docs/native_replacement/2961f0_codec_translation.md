# TU1.5 2961F0 translation codec

The shared DATA kernel and physical/source adapters are implemented. The
three qualified production entries and their generator hooks are installed;
final installed acceptance passed from an immutable source copy.
Frontend parsing still refuses unresolved translation/scale channels.

## Owning source

The complete fifteen-site TU1.5 body occurs in Primary, AI-frame and
ModelRender. The original XBE is pinned to
`21b207e7efdacaf6124a0822837f8be570766a42505057f7fd2d2ba8f409c4fd`.
`native_codec_translation_replacements.py` authenticates twelve complete
current/fresh/raw/prepared body/resolver/dispatcher/LiveState tuples. Exact
identity-selected operands and instruction-literal spelling are the only
qualified source projections. No other image/default is qualified.

The kernel reuses the ordered DWORD-copy algorithm. The view acquires the
index, factory, row offset and output pointer in source order. The first
source load precedes the output ADD and its flags. Three scalar stores keep
forward aliases, and the last source read publishes ECX rather than EAX.

## Source continuation

The source view reacquires live GP values after actual providers. Ten
checkpoints follow completed I/O and destination-register commits. Revoked
instruction/observer policy resumes the exact original next statement;
every label must be adjacent to its authenticated callback. A per-invocation
token prevents consumption of a provider's unrelated continuation exception.

Scalar stores preserve retained `w()`'s entry-selected empty-observer path.
An observer installed by the completed write applies to subsequent stores.
For an initially present observer, clearing it during the preimage/write
still suppresses its late delivery. The original retained body is unchanged.

## Limits

Physical transport admits readonly GP/Before/observer providers and separately
proves hostile incidental host-FP isolation. Source transport qualifies the
measured GP/XMM/flags and instruction/observer-policy feedback while keeping
source FP metadata and host FP controls/status readonly. It does not adopt
deliberate source-API FP mutations. Dense and opaque MMX ownership remain
distinct; no metadata is cleared to pass admission. Unmasked/pending FP,
unrepresentable files, signals/MMIO, partial provider stores and broad runtime
or parent closure remain separate.

All completed runs removed their owned builds, binaries and banks. Only small
reports, commands, hashes and failure diagnostics were retained. The installed
gate removed its copied source/build/banks through `tools/run_test.py`; its
retained compressed source manifest is 990,633 bytes. No binaries, raw banks
or dependency copies are retained. The later scalar296220 default insertion
is outside this immutable translation acceptance scope.
