# Model marker lookup (1E11B0 / disc 1DC8F0)

The installed native kernel replaces the recovered model-marker ID lookup
with typed guards and the shared first-equal ID-search algorithm. It preserves
the signed count, twelve-byte row walk, low-word datum indexing, authored
global/slot/row reads, saved-SI aliases, returned registers and original flags.
A separate raw adapter publishes the complete owning ABI.

Production defaults are installed in all six compatible source units and the
actual Effect helper. Qualified source contexts include
the real Effect helper, four TU1.5 forwarding copies (Primary, AI frame, Scene
and Sandbox), mapped Motion's TU1.5/disc branches, and the fixed disc
DeathStartup State. Animation selection's same numeric name has another
identity and is excluded.

The 28 unique original instruction sites are independently checked against
unchanged TU1.5 and disc i386 images. The accounting body metric is 37; it
must not be reported as original instruction coverage. Checks include all
GP/flags/XMM registers, FP controls/status and dense logical 80-bit lanes,
ordinary backed banks, explicit ordered accesses, atomic provider failures,
completed-store observers and opaque MMX metadata. FP-hostile providers use
the previously qualified RawScope/SSE-MMX ownership utilities.

The actual Effect API proof uses the complete real dispatcher CPP. Forwarding
proofs instantiate exact raw and prepared function bodies, and DeathStartup
uses its actual separate State/software-MMX type. Positive forced-reference
runs prove genuine retained statement delivery and complete normal ABI/access
results. They do not assert retained-source pre-I/O parity: legacy undefined
shift flags and retained PUSH failure ordering differ from original hardware.
The native packet proof uses the unchanged CPU as its authority.

The independent reference control is HALO2_REFERENCE_MODEL_MARKER_LOOKUP.
Admission retains unknown/tracing/replaced callback fallbacks, revalidates
live cursor/type/executor/protocol and observer witnesses, and refuses
unsupported FP/backend states. Fixed DeathStartup's pre-existing active-MMX

## Fresh Sandbox preservation

Full fresh generation exposed historical source drift before marker
installation. Its dispatcher and direct 1088E5 call bypassed the canonical
TU1.5 CABC0 required-owner/reset boundary. Four complete old/fresh target body
contexts also differed in exact observer or fallback spelling. The Sandbox
wrapper now authenticates each full resolver/dispatcher/body input and
restores only the explicitly pinned canonical identity projection. MapPack's
local CABC0 path is preserved. Canonical runtime bodies are unchanged.

The expanded preservation gate compares all 133 complete target bodies and
dispatch clauses, rejects ten exact drift controls, compiles the complete
fresh unit, and tests real State.required transport including direct CALL
stack/store protocol. Other callees are entry observations, without supplied
outcomes; this gate does not qualify their algorithms or physical faults.
The original semantic-drift diagnostic remains separate.
