# Private integer FP ownership

The new integer-only scope keeps every logical x87 lane and opaque MMX alias in retained State. It never interprets those payloads, clears active_mmx, or executes source floating-point arithmetic. It parks an empty host x87 file for C++ providers, restores the exact per-I/O environment after returns and exceptions, and adopts a genuine child's retained State controls/status before continuing. On release it restores the caller's host payloads, tags and TOP while carrying source CW/SW/MXCSR for the outer State.save boundary.

The dense RawScope and SSE/MMX scope are unchanged. This private utility admits valid masked dense states or opaque TOP0/depth0 MMX states; unmasked controls, invalid topology, source arithmetic, arbitrary policy-mutating providers and unsupported descendant outcomes remain outside its intended domain. Host C bits follow the declared source handoff; the pre-existing outer runtime C-bit restoration limitation is separate.

The direct-child proof uses the genuine already-qualified FC510 algorithm and independently unchanged original i386 code. It does not replace required-owner transport or override WorldState.required's active-MMX refusal. The exact guarded-header GCC/Clang sanitizer receipt covers 608 original paths, including all 256 opaque masks, 1,216 genuine numeric child calls and 5,760 complete packets per compiler. Each also checks 2,432 hostile I/O return/throw boundaries and 1,024 genuine World active-MMX required refusals, with both present and absent providers. Unsupported-backend parsing and refusal pass. Owned trees were removed, with no large retained artifact.

The later host-tags receipt repeats the full corpus with finite, signed-zero, subnormal, quiet/signaling-NaN host payloads, dense/sparse files, all TOP values and full MMX-style tags. Both sanitizer compilers pass and both trees are removed. Evidence: build/test-results/native-integer-fp-scope-host-tags-private-20261110/report.json; earlier receipts are retained separately.

The later isolated provider proof executes the genuine Effect FC510 API through actual required-owner transport, while the separate FP-changing proof uses the qualified tick and sphere algorithms to retain newly raised x87/MXCSR bits. Required_ABI_FP_fence.md records those receipts and the bounded permanent regression. Complete BACD0 opaque-MMX parent composition remains pending: current BACD0 default admission is dense only. No production caller or default widening uses the private integer Scope.
