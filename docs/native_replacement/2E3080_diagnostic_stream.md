# TU1.5 diagnostic stream controllers

Four exact native defaults are installed in the sole complete MapWorld source
owners: `2E3080` print controller/frame, `2E30E0` dynamic flush tail,
`2E2D10` formatter handoff, and `2E2E00` typed byte-length loop. Their 27, 3,
1, and 8 original sites total 39. The native DATA policy reserves the message,
calls its real formatter, measures the resulting bytes, appends through the
actual writer method, and releases the frame. Flush retains its real dynamic
tail owner. Refused inputs execute the exact old source continuation.

This is controller ownership, not all-native diagnostic closure. `32BA80`
and its executed CPU children remain exact compiled **retained** Primary
reference bodies in the proof. Buffered writer/copy children
`2E3DB0`/`2E3E70`/`2E3D60`/`2E2E30` are disposable generated **retained**
reference bodies. Their results are computed by the actual algorithms and
compared with unchanged i386; no child result is supplied. The default
`2E1C80` debugger/stdout path remains an unresumed genuine entry boundary.
Whole singleton/constructor execution, platform service returns, older-image
diagnostics and native dependency closure remain open.

## Authentication and production integration

`native_diagnostic_stream_replacements.py` authenticates all four complete
original bodies, the full resolver/dispatcher/LiveState/public run/owns context,
and exact identity operands. It strips only each exported exact prefix.
Current selected bodies and fresh identity-literal bodies have separate full
pins. Fresh public case ordering and an unused historical x87-helper C1
difference are retained as distinct exact contexts, without global normalization.

The installed owning hook in `generate_map_world_support_tu15.py` runs **after**
actual export renaming. The shared generator remains unchanged. Removing the
four prefixes and their single include reconstructs the original MapWorld CPP
byte for byte. The catalog authenticates each source-only prefix independently;
runtime admission and dependency closure flags remain false in that catalog.

Admission requires the exact live TU1.5 callback/cursor/type/executor/position,
three service sites and trace policy, a store-observer witness when needed,
and supported dense masked x87/SSE state. Cleared or rebound callable witnesses
refuse. Constructed-empty services have a separate conservative path. Opaque
MMX, unmasked FP, arbitrary provider/policy mutation and physical partial-write,
signal or MMU behavior are outside this qualification. The independent
`HALO2_REFERENCE_DIAGNOSTIC_STREAM` control preserves the retained route.
