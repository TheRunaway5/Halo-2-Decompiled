# Simplex face refinement (`30D1A0`)

The complete 131-site owner has a private shared typed DATA kernel and a raw
caller-frame ABI adapter. Both Primary and Death copies are now default native
within the admitted dense, masked FP and live cursor/provider contract. The installed triangle child
and the larger `30E930` controller are separate qualification scopes.

The algorithm streams the three immutable signed-byte face pairs, checks both
live scores, computes four ordered dot products, invalidates one inconsistent
candidate and returns the first positive face. Both indices are acquired before
the first score test. The current vertex cursor remains real private frame
storage; the point argument is acquired after both vertex reads and seeded
immediate-SHL flags. Dot products finish around their four real scalar stores,
rather than collapsing into an eager local calculation. The cursor is reread
and advanced even when a candidate pair is rejected. Final score reads and the
four distinct SI/BX/BP/RET epilogues preserve caller-frame aliases.

Primary and Death own the two complete source copies. Their body pins are
`2f64e35aeeb2232dfb02a2426a0bef6c5ac794e0c145a53e29bf2d107cb3ff06`
and `747e16bb89ef518bf8a9ea41b957b80be85b8c2e788071e581f79247ea8c91f7`.
The actual immutable table bytes at `41D760` are `02 00 01 02 00`, and the
comparison constant at `46A0E8` is positive zero. The policy still preserves
signed-byte addressing; no clamping or inferred bounds are introduced.

The initial GCC sanitizer proof passes 192 complete source-backed transactions,
436 retained read/observer prefixes, all 131 sites and all four return choices.
The independent unchanged-i386 proof passes 224 whole calls and 11,502 full
pre-I/O GP/full-flags/XMM/CW/SW/MXCSR/live80 packets, full banks and every ordered
store. Its inputs include rounding/DAZ/FTZ, IEEE edge words, all stack alignments,
live x87 depth through six and real scratch/score/vertex aliases. No original
code, numerical outcome or register postimage is supplied to native execution.

Normal source comparison uses the unmodified complete body. The retained
prefix reference explicitly hashes CPU-atomic PUSH, seven FLD, five FCOMP,
two FMUL, one FCOMPP and two native immediate-SHL flag primitives. This is
separate from unchanged-i386 hardware authority; no FP or flag bits are masked.
Physical page-fault atomicity, unmasked/sparse/MMX FP, capacity overflow and
arbitrary GP/policy-mutating providers remain outside this private proof.
