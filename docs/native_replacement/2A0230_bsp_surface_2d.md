# Native 2D BSP traversal (`2A0230`)

The shared typed kernel follows the signed child halves through packed 2D BSP
nodes, caching the node-array owner and preserving lazy point/plane reads. SSE
operations retain original order and precision. The normal ABI adapter publishes
all GP/XMM/flags, caller FP state and cursor before each observable access.

AI-frame and death-cycle bodies use separately authenticated whole-body and
selected-resolver pins. Fresh generators emit a second pinned literal shape;
its only difference is removal of identity-selected operands. The primary unit
has no body and uses the authenticated actual-owner fallback. Each route obeys
`HALO2_REFERENCE_BSP_SURFACE_2D`; raw/tick/epoch reference switches are independent.

The final component cohort passes GCC ASan/UBSan, GCC Release and Clang:
896 full comparisons over 128 unchanged-i386 cases and seven routes, all 30
original sites, 4,544 complete intermediate GP/flags/XMM/FP/logical-80 packets,
and 29,736 explicit reads. It covers aliases, wrapped/unaligned addresses,
signed children, looping traversal, FP special values, DAZ/FTZ, rounding and
precision controls, and live x87 depth up to eight. Ten body/resolver changes,
two dispatcher changes and nine unsupported admission protocols are rejected.
Forced reference measures six genuine callbacks, PC `2A028D`, EAX `FFFFFFFF`.
Complete fresh AI/death generation and syntax pass. Later fresh primary
generation preserves the actual-owner receipt through its authenticated
additional `FA5D0` dispatcher case; that case remains translated.
