# Actual TU1.5 126640 arena initialization

The typed kernel and separate ABI transport are installed for the narrowly
qualified callback-free TU1.5 producer and the prepared callback-bearing World
producer. The exact complete retained body remains the explicit reference
path. Raw callback-bearing source, fixed MapPack 1.1, generic tracing and
instruction census, bulk-write shortcuts and all-native child/runtime closure
remain outside this delivery.

The actual TU1.5 owner has 45 instruction sites. Its canonical Arena name is
125280; 126640 is the actual executable entry. The superficially similar
DeathStartup body is fixed MapPack 1.1, with literal 1.1 operands and callees.
It is outside this TU1.5 qualification and remains retained.

The shared typed flow owns initialization, reservation sizing, word clearing,
metadata/root allocation accounting and publication. The ABI adapter owns
source register/flag publication, lazy reads, saved frames and actual child
handoffs. Reservation uses the authored extra 0x40000 plus usable 0x3BE000
bytes. The REP span is 0xFF800 words, or 0x3FE000 bytes. The CRC input is each
four-byte allocation size word, not the allocated metadata block.

## Distinct publication protocols

Physical PUSH commits SP after a successful write, and physical REP advances
DI/ECX after the write before a completed-store observer. The retained virtual
source API decrements SP before PUSH preimage/write, and advances REP DI/ECX
after its observer returns. Both policies are explicit in the private adapter.
The production shared State bases have not been changed. Source-provider
exceptions, CPU instruction-prefix stops and actual partial-page faults are
not interchangeable domains.
