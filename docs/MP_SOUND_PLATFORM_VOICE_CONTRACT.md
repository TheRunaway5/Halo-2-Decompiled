# Native platform voice contract

The SDL extension can supply real device, PCM queue and completion services to the source CPU sound owners. It must preserve each requested voice and packet until the owner releases it; it must not choose a permutation, cap or steal voices, invent a listener, or announce source scheduler admission. The existing generic menu `AudioEngine::play` remains a separate path. This contract is based on unchanged original instructions, independently matched against the authenticated user-owned1.5 image, plus separately executed scalar controls. It is not an executed accepted21F220 playback trace.

## Authority

The source images are disc1.1 SHA-256 `aaea4c9c58ac02cf5f9cc97a16d688318c59b652e92301078e2547a2a5ea5377` and authenticated1.5 SHA-256 `21b207e7efdacaf6124a0822837f8be570766a42505057f7fd2d2ba8f409c4fd`. Forty-three complete CPU bodies, every internal branch and mapped call target, match uniquely. Only immutable parameter words are imported; runtime globals, pointers, driver and voice state remain inputs. Both images independently execute the complete12C760 normalization query, complete221760 relative-rate query, and explicitly bounded221B90 pitch/gain slices. The11,360 scalar controls per image comprise3,168 normalization cases,4,096 pitch slices,2,048 gain slices and2,048 relative-rate queries under eight declared FPCW/MXCSR pairs. Zero/tiny/reversed/NaN ranges, bool bytes0/1/2/255, finite boundaries, infinities and NaNs are retained. Results are raw words, not expected values derived from native code. The query's declared integer backing is a scalar input, not an allocated voice or initialized audio system. This relative rate is the source-owned rate multiplier appropriate to already resampled PCM; the backend must receive the actual result rather than recalculate an ideal `pow(2,pitch/1200)` or treat the integer as hertz. ## Packet submission and completion

The24-byte packet ABI is+00 data,+04 byte count,+08 completed-size pointer,+0C status pointer,+10 union packet-context/completion-event,+14 timestamp pointer. The retained primary compatibility header corroborates these names; original instructions are field/store authority. This corrects an earlier investigation message which mislabeled+14 as an event field. [Retained ABI declaration](../analysis/multiplayer/map-pack/smg-audio-startup/reference/cxbx-585c49a/XbDSoundTypes.h).

The stock encoding0/1 codec2B4CE0 obtains the actual loaded chunk and cache data pointer. Its offset is `min(stream+2C,max((chunk_size&3FFFFFFF)−72,0))`; byte count is the remaining extent. It writes the actual chunk pointer at packet+10 and NULL completed-size/status/timestamp pointers. The72-byte tail clamp is literal code even in this shared codec; it is not an inferred seeking/alignment rule.2B4D60 increments the submitted count and resets offset0 after a real accepted packet. [Packet builder](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/002b4ce0-old.asm), [accepted submission bookkeeping](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/002b4d60-old.asm).

2B4B30 runs only source stream states2/3. It requires a successful real status query with accepts-input bit0, an actual queued-but-unsubmitted chunk, and the codec packet result. A successful Process calls packet_submitted; failure calls packet_failed. After one or more successful submissions it calls Discontinuity. The platform must retain both selected packets in their original order, their private source/chunk tokens, and the owned bytes/PCM until real completion or flush. It must not select or decode the next permutation inside an unsolicited loop callback. [Actual service order](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/002b4b30-old.asm).

The real callback222840 receives `(channel_context,packet_context,status)`. It validates the channel and nonNULL packet context, invokes the codec's chunk_finished for **every status**, then pumps another packet only when status0 and source stream+3 bits0Ch are clear.2B4DD0→2B48A0 removes the completed chunk, updates queued/submitted counts and state, shifts the retained queue, and releases cache pin/reference counts. A successful callback is justified only after actual native PCM consumption; flush/error must produce actual non-success completion. For the stock packet its completed-size pointer is NULL: per-packet completion, status, context and ordered lifetime are mandatory; a fake intermediate compressed-byte cursor is not required or authorized.12BBA0 separately tracks sample progression using the source clock and221760 ratio. [Completion owner](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/00222840-old.asm), [dequeue](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/002b48a0-old.asm), [reference cleanup](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/002b4dd0-old.asm), [sample progression](../analysis/multiplayer/integration/sound-platform-voice-contract/paired/instructions/0012bba0-old.asm).

A minimal parallel native API can therefore create a real private device/stream handle; accept explicit relative rate, integer source volume, pause state and output routes; enqueue owned PCM packets with caller tokens; report actual queue capacity/pause/errors; return ordered completion events with original tokens; flush pending packets with non-success completion; and destroy the private handle only after owned pending buffers are accounted for. Missing parameters stay unavailable, rather than gaining unity rate/gain, pan0 or a guessed speaker layout. The backend must not impose a32-voice cap or steal. Source scheduler73 static policy slots,51 shared voices, class limits and arbitration are separate CPU owners. Platform callback delivery/poll latency and resampling are explicit native services, not claims of Xbox DSP bit/latency parity.

```sh
.tools/python/bin/python tools/research_sound_platform_voice_contract.py --output <new-paired-directory>
.tools/python/bin/python tools/oracle_sound_platform_parameters.py --output <new-scalar-directory>

```

The research tool's pinned paired report is a fixed dependency of the scalar oracle; its source words/bodies cannot silently change. [Final manifest](../analysis/multiplayer/integration/sound-platform-voice-contract/final-manifest.json) records the independent repeats, original inputs, source tools and current backend snapshots.
