# CTF/Assault System Link return

`SystemLinkSession` owns the native raw-LAN lifetime across gameplay worlds.
It is separate from the offline Vista session and the ONLINE service. Its
phases are native port states; they do not assign Xbox/Vista membership,
lifecycle, readiness or account flags.

The actual socket, independently exchanged host key, authenticated peers,
selected local profiles/teams and random per-room presentation identities
survive the return. These presentation identities are not Xbox Live XUIDs.
The host detaches its match pointer only after original completion, frozen
statistics and confirmation against each peer's actual final native snapshot.
World-dependent cameras and snapshot storage retire before world destruction.
The lobby services no gameplay owner and cannot read a departed world.

Original objective/PCR option projection, retained player/team statistics and
the original ranking comparator feed the existing native PCR consumer.
Source player slots remain sparse when a participant leaves; neither scores
nor identity rows are compacted. The original PCR input kernel lets the host
continue and gives a nonhost the actual leave dialog. Host Done publishes the
retained lobby and allocates fresh lobby navigation on each peer.

The existing native countdown start/timer/sound kernels own the next Start,
ten-second countdown, four final beeps, quick advance and cancellation.
The native session supplies actual clocks, host permission and admitted local
profile input. A new source world joins retained remote participants through
the genuine player/profile owners. New world cookies reject late old-world
snapshots/inputs while retaining the established cryptographic sessions.
Input pulses, held actions and snapshot baselines reset for the new world.
Preparing a world does not manufacture an accepted input or liveness packet.
Actual native snapshot/input admission gates the next gameplay clock.

Authenticated arrivals can join a world-free lobby without receiving a
fabricated gameplay snapshot or the previous match's results. Interactive
objective `--join` first selects real native local profiles and teams, using
the authenticated host's map/rules. The native query also supplies its actual
scenario leaf. A retained client checks its independently prepared content
fingerprint and selected profiles before consuming the next Start.

The 57 Xbox TU1.5 objective rule owners and original 304-byte option schema
remain the gameplay authority. No executable payload or runtime instruction
decoder is introduced. Other engine families, migration, original Xbox wire
compatibility, physical played routes, framebuffer/speaker comparisons and
launcher installation retain their own acceptance scope.

Validation is being recorded under
`build/ctf-assault-system-link-20261025`. Qualification is complete only when
its final acceptance and cleanup receipts report success.

The retained-session regression covers Multi Flag CTF, CTF Classic, 1 Flag CTF,
1 Flag CTF Fast, Multi Bomb, Single Bomb, Single Bomb Fast, Neutral Bomb and
Blast Resort. Each case completes an original native match, independently
confirms its final replicated results, releases the world, exercises PCR Done
and nonhost leave/cancel, allocates fresh lobby navigation, idles for 120
updates, cancels/restarts the original countdown, hears its four final stages
and admits the next source world on the retained socket/key. A UDP proxy delays
genuine encrypted packets until the new world; it never decrypts or edits them.
The test rejects stale PCR continuation and a mismatched preparation without
consuming the retained connection.

Single Bomb adds a genuine arrival while no world exists, three-player match
completion, authenticated departure, a host change to 1 Flag CTF Fast and a
third completed world with sparse source slots. The ordinary runtime regression
uses `run_multiplayer` and its actual quiescent authority release rather than
calling source ticks recursively from a fixture. Declared positions and actual
controller press/release samples are inputs; no score, timer, winner, readiness
or completion result is supplied.

The control channel is part of this port's authenticated native protocol. It
does not claim original Xbox wire interoperability. Local couch selections
remain the actual admitted profiles; retained nonhost setup/couch editing and
host migration are separate features. The source qualification uses a frozen
coherent cohort because other work is active in the shared checkout; its exact
hashes and subsequent narrow repairs accompany the results. Whole-file hashes
of concurrently changed source are not represented as tested workspace hashes.
