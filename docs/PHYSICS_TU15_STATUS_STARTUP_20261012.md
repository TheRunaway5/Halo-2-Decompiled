This component completes and immediately connects the original settings return
path to the public fresh TU1.5 startup composition. It does not complete player,
vehicle or object physics. Timer149, full process startup/heap installation,

## Owned original reference and native resource

The named reference for export301 is the user's modified Complex4627 BIOS in
xemu0.8.136. Two independent isolated boots retain identical complete208-byte
`RtlNtStatusToDosError` code and its828-byte range and1,530-byte value tables.
The function SHA-256 is
`9473f53e951680c531d3e341264567df38def483706d340f709d0c9e99ad1a26`.
The tables contain103 records including the final zero sentinel and765 value
words. Two earlier capture attempts rejected that observed sentinel; their
logs are retained as failed attempts. No title/DVD is selected during capture.
Private EEPROM copies and HDD overlays preserve the original resources. These
captures read memory only and do not invoke or patch guest code or registers.
This establishes modified-BIOS resource bytes, not physical Xbox behavior.

`SourceTu15StatusTables` requires those exact table extents/fingerprints and a
named resource, mounts immutable banks at the original addresses and validates
them before use. No platform error mapping, compatibility default or captured
world data is substituted. The generated runtime statically lowers the complete
59-site routine into native control flow. Production has no kernel instruction
fetch, decoder or original-code execution. GP registers, partial register
writes, flags, three stack stores, return cleanup and ordered reads follow the
original code. FP/XMM state remains unchanged by this integer-only routine.
