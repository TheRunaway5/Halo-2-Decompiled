# Native TU1.5 unit speech reservation

This closes the actual `116C00` reservation-check dependency graph:
`116B80` source lookup, `213890` permutation eligibility, `21FE40` sound-class
history prefix, and `140EA0` history width. All five owners are structured
integer algorithms over the real object, tag, sound-class, gestalt and history
owners. No original dependency result, provider success, virtual CPU state or
instruction-dispatch implementation is used.

The API is `include/halo2/native_campaign_ai_speech_reservation_tu15.hpp`.
`cmake/CampaignNativeAiSpeechReservation.cmake` adds the source to the physics
runtime and registers its independent original-reference test. This module
does not enable a live route, whole audio group, or completed speech request.

## Behavior and caller contract

* The object pool resolves the actual unit body. Its signed `+342` offset owns
  the speech state. The source lookup reads the unit's dialogue tag, validates
  the signed action index, reads the action's sound and consults live sound
  eligibility. Its output DWORD is always read and is written only when its
  previous value is nonzero. Its boolean result is independent of that output
  publication condition.
* The eligibility owner requires one pitch range, resolves its actual class
  and range metadata, computes the source's unsigned minimum-one history width,
  and checks all five live eligibility bits in order. Class indices are signed
  bytes and range/count operands are signed words; history bit addressing keeps
  the original arithmetic shift and low-five-bit mask.
* Reservation first reads the optional selected-sound field. Only `NONE` plus
  an action other than `-1` invokes source lookup. The source lookup's boolean
  is intentionally unused here: the original subsequent gate checks whether
  it produced a sound datum. A preselected datum, including zero, follows the
  actual original policy without manufactured metadata validation.
* The real unit flag allows the special priority15 path. Current priority zero
  admits before comparison; priorities13/14 permit equality, ordinary
  priorities require strict greater-than, and priority12 observes the current
  active flag under the original short-circuit conditions.
* The selected-sound field publishes before the optional prior-reference field
  is loaded from speech state `+44`. The raw-address overload supports aliasing
  outputs and aliases of the unit state. The typed
  `NativeCampaignAiSpeechResolvedSound` overload transports the actual caller's
  private output, sharing the same algorithm without constructing source stack
  addresses. Local output values are compared at every original engine read.

The genuine caller receipt executes `117240` from its entry, through its private
output initialization and actual `117276 -> 116C00` call, and stops at the
natural `11727B` continuation. Three priorities cover both reservation outcomes.
The resulting source, action, priority and three stack arguments are captured
from that call. This receipt does not execute or qualify `117240`'s subsequent
timed request construction or `116D60` submission.

## Independent reference and limits

The reference executes the unchanged SHA-256 pinned TU1.5 image in a physical
i386 process. The final corpus contains 202 completed calls and one genuine
fault prefix, reaching all 220 sites, with 5,708 ordered reads, 236 stores and
32,815 original instructions. It compares every read's value and preceding
store count, every store's before/after bytes, all retained banks, result widths,
preserved caller registers, full SIMD state and occupied extended operands.
The algorithms perform no floating-point operations, including with all eight
extended slots occupied.

The `21FE40` zero-global-count path is not a synthetic `NONE` result: the
original clears its reference and faults at the actual address4 read. The
physical receipt observes that SIGSEGV and address. The native memory owner
likewise fails at its address4 read after exactly the same committed prefix.
Other unmapped-input fault prefixes remain outside the matrix.

Cases include signed action/count extremes, range and class negative offsets,
32-bit history width extremes, all five eligibility bit positions, history-word
crossings, missing tags/sounds, zero/nonzero output slots, the priority policy
matrix, unit flags, aliased output/current/prior fields and the real private
caller slot. Six mutants reject zero-slot publication, ordinary priority
equality, priority12 equality, omitting the fifth bit, reversing output order,
and changing the class history flag.

Evidence is under `analysis/campaign-native-speech-reservation-20261028/`.
Existing speech queue, choice, cancellation and audio algorithm proof sources
remain unchanged. Full `117240/116D60` submission, `213D30` dispatch,
`214EA0/214710` collection/scoring, `215390/2175A0` publication, and the complete
request-`0x34` behavior cancellation composition remain open.
