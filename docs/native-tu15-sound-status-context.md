# Native arithmetic status context

`halo2::tu15_status_context::Status` retains an opaque24-bit value, a known-bit mask and per-bit provenance. Unchanged bits keep all three. Numeric consumers must request their required bits with `numeric_value`; unresolved bits cause rejection. Incoming evidence labels are caller diagnostics and do not authenticate a reset, installation, frame, device or boot receipt. No default Xbox status is supplied.

The record0 API in `halo2::tu15_record0_context` requires established-clear scaling, compatibility, double-precision, loop, sixteen-bit arithmetic and saturation mode bits. It preserves the approved canonical eight-route profile and exact repeated output owners. Actual arithmetic/transfer witnesses establish only their written bits; unknown sticky bits remain unknown without a witness.

This interface covers record0 only. Authentic boot/modifier/interrupt ownership, other records, full legal mod support and initializer45 readiness remain separate required work.
