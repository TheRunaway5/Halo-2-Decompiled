## Bind the complete generic caller without fabricated state

`construct_source_object` requires read/write span providers, actual selected type`+8` extent, and an invoke provider before entry. Its state contains four **owned pointer cells** for object pool, tag table, world and clock, plus an owned C8 invocation frame. The header descriptor is read at `+20` capacity and `+44` header pointer; body pointers come from the same shared12-byte headers used by `SourceObjectBodyStorage`. Tag resolution reads low16-indexed16-byte slots' `+8` address. Real callbacks may relocate bodies; preserve original rereads, frame locals and shared MXCSR. Do not independently allocate or mirror the object headers. [Generic contract](../include/halo2/object_construction.hpp), [complete native caller](../src/object_construction.cpp#L63), [persistent body API](../include/halo2/source_object_body_storage.hpp).

The pool descriptor read facade can expose capacity/header pointer directly from the current `NativeObjectLifetimes`/`DatumPool` owner, with `SourceObjectBodyStorage::headers_address` as its token; lookup consumers also need actual stride/high-water. The storage adapter maps header/body/scratch but does not create those four slots, a raw pool descriptor, raw tag table, source world or clock. These remain explicit environment ownership. `Cache::tags()` and `SourceTagMetadataStore::index_address_provider()` already retain actual tag groups/addresses; a narrow raw-table read facade must use those current cache entries, not an executable BSS snapshot. The generic world/clock state must be supplied when reached; absence is not a zero/default world. [Shared pool accessors](../include/halo2/datum_pool.hpp), [current storage resolver](../src/source_object_body_storage.cpp#L46), [tag-table slot provider](../src/source_tag_metadata_store.cpp#L44).

Use `SourceTagMetadataStore` for readonly payload resolution; existing lower `C0890` unusually routes reads through a mutable-span service, so `SourceMutableTagStore` is already available for a single owned mutable resident copy shared with such lower owners. Neither store creates a raw tag table, initializes resource fields or activates the map. Type classification needs the actual tag-group DWORD at the **signed low16** definition index, separately from the definition's own signed type word. `OriginalData` now imports all13 base extents, construction operands and pressure constants; its selected immutable ranges can compose with this environment. [Readonly store](../include/halo2/source_tag_metadata_store.hpp), [mutable store limits](../include/halo2/source_mutable_tag_store.hpp), [type contract](../include/halo2/object_type_construction.hpp), [current imports](../src/original_data.cpp#L305).

## The first missing resource owner is not the new body heap

`148360` first reads actual busy byte`486563`; if clear it calls `148740` **before** setting busy. `148740` reads second/first overflow pointer slots`480DA8/480DA4` and their signed counts`+20`, then main pool slot`480DA0`. Main pressure consumes signed`+F0340` and actual `22ECB0` sixteen triples (`+F0384,+F03C8,+A8`, descending), under imported FP constants. This is a different heap/state contract from the new `100000h` object-body heap and its free-byte counter. Substituting body-heap free bytes, null pools, forced busy or pressure0 does not produce this owner. [Complete pressure instructions](../analysis/damage-shields-goal-20261011/overlay-pass/registration/generic-binding/instructions/00148740-tu11.asm), [statistic instructions](../analysis/damage-shields-goal-20261011/overlay-pass/registration/generic-binding/instructions/0022ecb0-tu11.asm), [native pressure contract](../include/halo2/object_preparation_pressure.hpp).

The broader retained pressure environment must supply busy`486563`, collecting`486562`, last tick`480D8C`, the heap pointer cells/records, clock pointer`518444` and its current tick`+8`. At pressure>=2, required real calls can include `1C7EC0`, `1C7970`, `1C6100`, `1C5FF0`, `1482F0`, plus existing complete collector`148510`. None has a live generic-constructor provider in the inspected source. A legitimate quiet branch is possible **only when produced by actual initialized/current heap ownership**; an original capture or nominally empty object body arena cannot establish it.
