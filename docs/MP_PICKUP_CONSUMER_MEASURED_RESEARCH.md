# Measured original capsule inputs and pickup side normalizer

A separate unchanged-instruction [oracle](../tools/oracle_mp_pickup_consumer_measured_1_1.py) now measures the missing current inputs and internal normalizer outputs in the actual allocated/equipped Lockout fixture. It captures **207 original `C57A0/E0C20` calls** and **187 original `30BD0` executions**. Per-call crouch/header/parent, metadata, source root, capsule outputs, normalizer input, raw x87 state, float32 length spill, reciprocal, normalized output/return and selected side vector are actual runtime observations. No expected geometry is reconstructed or supplied. The earlier [observed export and its historical gaps](MP_PICKUP_CONSUMER_FIXTURES.md), [outer fixtures](MP_PICKUP_OUTER_FIXTURES.md) and original reports/tools remain frozen and unchanged. [Measured report](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/report.json), [independent audit](../tools/oracle_mp_pickup_consumer_measured_audit_1_1.py).

## Original repetition and read-only measurement

Before adding the observations, both complete original fixture mains reproduced their frozen reports byte for byte. The added measurement then reproduced those same original baseline reports again, including every original call/query, source resource record and instruction-listing hash. The wrapper compares and suppresses writes to existing frozen listings; it never overwrites source evidence. Fresh baseline names are separate ignored files: `consumer-preflight.json` and `consumer-measured-baseline.json` within each original suite directory. Only the new report owns the additional observations. The measured report reproduces byte for byte in a second independent process. [Preflight/baseline records](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/report.json), [visibility original](../analysis/multiplayer/integration/inventory-source/pickup-visibility/report.json), [retreat original](../analysis/multiplayer/integration/inventory-source/pickup-retreat/report.json), [second measured report](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/reexecution/report.json).

The extension inherits the original constructors, selected combat idle185, current graph pose/attachment, real SMG allocation and authored BR0/BR1/SMG12 allocations. Original authored/proximity root inputs and the exact frozen fixture call order are retained. The added hook only reads emulator memory/registers and records data; it adds no object store, register write, service override, contact or source instruction. Its source mains and constructors remain the original frozen code. [Measured hook](../tools/oracle_mp_pickup_consumer_measured_1_1.py), [allocated/equipped fixture](MP_PICKUP_EQUIPPED_RESEARCH.md), [attachment producer](MP_WEAPON_ATTACHMENT_RESEARCH.md).

## Per-call capsule and object state

At each `C57A0` entry, the extension follows the actual source pool/header pointers and records both full datums, header bytes/type, body definition/parent/node/root/scale and body prefix. At `E0C20` entry it separately captures the unit body **`+2C4` current crouch**, actual resident definition pointer and exact metadata`+264..273` bytes. Original `BACC0` return provides the capsule's source root; original `E0C20` return provides bottom, extent and radius. Current header and parent fields are measured here rather than inherited from a constructor assumption. [Original C57A0 type/identity reads](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000c57a0.asm), [E0C20 ownership](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000e0c20.asm), [root producer](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000bacc0.asm).

All 207 observations have current unit header type 0, target header type 2, unit parent NONE, item parent NONE, **current crouch bits`00000000`**, and actual `bipd +264` flags 4. These are measured bounded results, not defaults for other source states. Source metadata standing/crouching/radius bytes are checked against untouched Lockout cache data. For this executed metadata branch, source `E0C20` copies the unparented root, adds metadata radius to bottom z, computes `(crouching−standing)*current_crouch+standing−2*radius` with separately rounded SSE operations, and returns the metadata radius. The audit checks every actual output against that exact source field/order contract. Different metadata flags, nonzero crouch and parented-unit branches remain unexecuted. [Per-call records](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/report.json), [E0C20 instructions](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000e0c20.asm), [audit](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/audit.json).

`FBFA0` entry/return separately captures actual item state and its source-produced interaction point. The two consumer calls after the conditional first-item tick use the original successful ground-marker/contact producer. Their original marker/node/plane records are retained in the observed export, while full Havok settling remains unavailable. Other consumer item points copy original unparented roots. Current item flags/contact fields and identities are exported, so a native caller cannot substitute a host grounding flag or definition identity. [Observed marker/contact records](../analysis/multiplayer/integration/inventory-source/pickup-consumer-fixtures/cases.jsonl), [conditional producer scope](MP_PICKUP_VISIBILITY_RESEARCH.md), [minimum live producer contract](MP_PICKUP_NATIVE_CONTRACT.md).

## Exact `30BD0` owning-stage observations

Only the actual `C57A0` call with return address`C5985` is measured as a side normalizer. The entry records the three input words at original EAX, source world-up/fallback pointer/vector, threshold/one constants and current FPU control/status/tag/MXCSR. The input is the actual stored cross-product vector; it is not rebuilt from cast deltas. Original x87 `FLD/FMUL/FADDP` forms x²+y²+z² and `FSQRT` produces length. Its actual length is retained in raw valid x87 register bytes and in the original float32 spill. [Original 38-row normalizer](../analysis/multiplayer/integration/inventory-source/pickup-native-contract/00030bd0.asm), [measured stages](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/report.json).

| Observation site | Owning source state |
|---|---|
| `30BD0` entry | Exact input vector, FPU controls and source constants/pointers. |
| `30BE9` | Before `FSQRT`: original x87 sum and raw banks/status. |
| `30BEB` | After `FSQRT`, before stack relocation: actual length in the current valid top register. |
| `30BF1` | Before `FST [ESP]`: same actual length after source stack pops; old spill is explicitly undefined. |
| `30BF4` | After original float32 `FST`: actual defined spill word. |
| `30C00/30C02` | Original threshold comparison and admitted scaling path. |
| `30C0F` | Before input-x load and `DIVSS`: XMM1 still contains original one. |
| `30C17` | After `DIVSS 30C13`, before the first `MULSS`: XMM1 is the actual float32 reciprocal. |
| `C5985` return | Actual normalized xyz, source XMM0 length return and spill/FPU state. |
| `C59AB` | Source-selected side vector after the caller's optional fallback branch. |

The raw state contains all eight emulator FP register representations plus `FPSW` TOP and full tag word. Only the valid top register at the length-owning stages is a defined length observation. Inactive banks and the pre-`FST` spill are provenance, not numerical expectations. The separate audit checks that the post-`FSQRT` and pre-`FST` valid top lengths agree and that their recorded value rounds to the actual source float32 spill. No host square root result is used as exported expected data. [Measured capture](../tools/oracle_mp_pickup_consumer_measured_1_1.py), [independent register/spill audit](../tools/oracle_mp_pickup_consumer_measured_audit_1_1.py).

The first measured input is `40D23806 412815B5 80000000`. Its valid length register contains little-endian raw80 bytes `00604DDB76563EC60240`, the actual float32 spill/return is `41463E56`, the actual post-divide reciprocal is `3DA54AAB`, and the original output/selected vector is `3F07BB6C 3F590E08 80000000`. These are captured words, including the retained negative zero. [First original normalization](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/report.json).

All 187 executions take the non-small-length path. Original source instructions then divide one by the stored float32 length and multiply each input component independently; XMM0 returns that stored length. Original threshold bits are`38D1B717`. The small-length return and caller fallback remain unexecuted, as do unordered-input cases. The actual controls are **FPCW`027F`, MXCSR`1F80`**, inherited from the explicitly configured [frozen `Trace.run`](../tools/oracle_smg_firing_1_1.py). This is the measured fixture's x87 precision/rounding environment, not newly recovered Xbox engine initialization. Source pose inputs retain the existing Xbox reciprocal boundary. [Normalizer source](../analysis/multiplayer/integration/inventory-source/pickup-native-contract/00030bd0.asm), [reciprocal boundary](SPARTAN_LIVE_POSE_1_1_RESEARCH.md).

## Source geometry, cast order and endpoint consumers

At `C5845`, the extension observes actual bottom/top/item stack buffers after the original capsule/item point producers. At `C59AB`, it observes the selected side vector. At `C5B4B/C5B70` it observes both target-side endpoint buffers before/after the positive clip's consumer; at `C5B8D/C5BB2` it observes them before/after the negative consumer. These are source stack reads at the owning stages. Exact source `16BAC0` endpoints, masks, start/delta, outer return/point and final consumer AL remain linked to the frozen observed export. Every capsule output and every final AL matches the original report. [Source stores/calls](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000c57a0.asm), [literal consumer casts](../analysis/multiplayer/integration/inventory-source/pickup-consumer-fixtures/casts.jsonl).

The measured set retains **1,513 actual consumer casts, 374 clear side clips, 21 visible and 186 blocked**. Both endpoint buffers stay identical through the clear-clip consumers. No clip-hit replacement store is exercised, and the extension does not supply a hit to cover it. The first/bottom/side visibility order and short-circuit result remain original; independent outer mask replays/retreat probes are not converted into consumer emissions. [Observed coverage](MP_PICKUP_CONSUMER_FIXTURES.md), [measured audit](../analysis/multiplayer/integration/inventory-source/pickup-consumer-measured/audit.json).
