# Native platform ownership joined to physics construction

`source_run_physics_world_with_native_platform` joins native critical-section operations to the recovered world graph. It takes the caller's actual memory/GP/SSE/x87 state, shared synchronization owner, thread/event services and remaining game owners. Unsupported calls delegate with that full state. Missing thread/wait/wake ownership stops without consuming the source return. Production contains no checkpoint restore, original executable execution, opcode decoder, recorded field results or fabricated heap/world data.

The combined graph now has 371 complete paired bodies and 30,717 statically lowered instructions. Nine additions over the initialization cohort cover heap cleanup and SEH epilogue, CRT copying, BSP progress/cache work and collision-shape construction. LEAVE updates ESP from the actual EBP and pops the actual saved EBP; flags remain unchanged. Full bodies, direct caller bindings and listings are authenticated against owned update 1.1 and TU1.5 images.

The platform adapter implements an explicit native void-call ABI. Retained public declarations specify one stack argument and stdcall cleanup. Each import caller's real pushed return word is checked against its selected image before reading the argument or changing memory. Successful calls consume eight stack bytes and preserve incoming register/FP state. This is the native adapter's defined behavior, not a claim about original Xbox kernel register clobbers. Every supported import caller in the recovered graph is bound: `2DACAD`, `2DB25E`, and cleanup funclet `2DB3D2`, with independently authenticated TU1.5 return words. Unknown callers are not admitted.

The independent oracle starts from the actual original construction-entry checkpoint. Before admitting platform ownership, it must exactly reproduce the earlier 17,504-instruction prefix and its ABI/stores. It then executes the original caller using the pinned compiled compatibility lock reference. A second execution defines the native preserved-register ABI and removes reference-private compiler spills. Source instruction flow, source written values and full critical-section transitions must agree. Six declared volatile GP/flag variations must also agree. They are bounded variations of this retained input, not a proof of every possible caller input or original kernel implementation.

The native comparison covers one 67,468-instruction construction prefix, 5,004 ordered source writes, four platform calls and 43,027 observed memory bytes. It checks native GP/SSE/x87 state, defined flags, complete source stores and observed banks. A second run through the joined public entry point must produce the same state and delegation. Separate checks cover all three call bindings in both image selections, wrong return words, missing identity ownership, unknown callers and absence of the callback. Update 1.5 is authenticated at the function/binding level and by retained earlier world regressions; this new full construction scenario is update 1.1 only.

Construction now stops at required owner `306F40`, reached from the BSP collision-shape constructor. That callee remains unimplemented. The actual entry checkpoint and compatibility reference are private validation inputs under `analysis/multiplayer/sandbox-source/physics-platform-call-runtime-20261011/`. They are not production resources or substitutes for native process startup. This source freeze inherits original test resources and is not a redistributable asset-free package.

Native process-heap/startup ownership, the remaining BSP/world/body/controller chain, live match movement replacing `CollisionWorld`, other shapes/motions, vehicles/ragdolls, Xbox CPU estimate equivalence, full TU1.5 startup and continuous all-map split-screen/LAN verification remain part of the active goal. These component checks do not replace the launcher or establish live gameplay parity.
