# Original F9B10/F9EA0 motion integration contract

Research date: 2026-10-08. This independent extension executes the unchanged first motion callbacks for the three allocated Lockout world weapons in the genuine source-created player/PVS/world fixture. It captures the complete item states, exact original service arguments and pointed buffers, consumed operands, branch/math CPU snapshots and ordered stores. **Every owning active-item runtime section reproduces byte for byte**; no guest input, activation, pose, contact, admission or service result is added. The preceding active-item freeze is unchanged. [Oracle](../tools/oracle_mp_item_motion_boundaries_1_1.py), [report](../analysis/multiplayer/integration/inventory-source/item-motion-boundaries/report.json), [audit](../analysis/multiplayer/integration/inventory-source/item-motion-boundaries/audit.json), [owning schedule](MP_ITEM_ACTIVE_SCHEDULE_RESEARCH.md).

The measured contract is suitable for a bounded native motion differential. It does not establish additional frames, continuous settling, a complete frame/session, local device ownership, positive Havok/object/instanced contact, actual audio playback or Xbox numerical parity. The inherited compatibility/platform/residency, declared tick/rate and selected startup composition remain the owning report's inputs. [Explicit owning boundaries](../analysis/multiplayer/integration/inventory-source/item-active-schedule/report.json), [player/PVS scope](MP_PLAYER_VISIBILITY_RESEARCH.md).

The report measures **FPCW=027F, MXCSR=1F80**, every x87/math checkpoint's physical Unicorn FP-register tuples/status/tag words, complete XMM128 words, source scratch frames and actual spill stores. It neither resets these registers per motion call nor recalculates expected lengths/vectors. Marker/transform composition includes **143860 ×2, 142D00 ×2, 1441D0 ×15**, with actual **0x34-byte (52-byte)** matrices before/after each interface. Preserve SSE/x87 operation order, aliased buffers and signed-zero words; console reciprocal/rounding/contact parity remains explicit. [Math/branch points and packets](../analysis/multiplayer/integration/inventory-source/item-motion-boundaries/report.json), [30BD0 bytes](../analysis/multiplayer/integration/inventory-source/item-motion-boundaries/instructions/00030bd0.asm).

For a native differential, use each core call's source full datum/header/body, definition bytes and current banks from `before_state`; deliver only its measured service requests with those original arguments and input packets. Compare the actual returned AL where defined, full body/current-node state, source world/registry/context/queue buffers, and ordered owning stores against `after_state`. Service outputs come exclusively from this original execution; the capture does not certify a native implementation of a missing live producer. Independently compare each implemented lower producer's packet/state/store interval before replacing its explicit boundary. [Schema and source audit](../analysis/multiplayer/integration/inventory-source/item-motion-boundaries/schema.json), [owning dispatcher contract](MP_ITEM_ACTIVE_SCHEDULE_RESEARCH.md).

Unexecuted source branches include FB620 impulse/RNG paths, F99A0's alternate orientation normalization, 10DB90's positive queue/body path, non-NONE physical/network/parent handling, F9EA0's alternate casts/rotation/counter paths, positive Havok delivery and FBAC0's nonzero sine/cosine branch.
