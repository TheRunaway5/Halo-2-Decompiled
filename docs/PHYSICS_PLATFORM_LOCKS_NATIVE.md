# Native physics platform synchronization operations

`PhysicsPlatformLocks` implements the source-visible 28-byte critical-section operations for the native platform layer. It owns serialized count/depth/identity transitions; caller-provided services own actual current-thread identity and contended waits/wakes. It does not provide Xbox thread structures, process-heap fields, world/body defaults, or an x86 callee ABI. Missing services stop with the already-performed transition preserved. In particular, a missing wait retains the increment, and a missing wake retains the release. There is no successful fallback or rollback.

The field contract is authenticated against the pinned compatibility sources retained in `analysis/multiplayer/integration/spawn-source/kernel-sync-world/`: source manifest `0813f92e273e295bfc7fa146555afcd6e752f73cc5295f305681dfd5bf54505e`, initializer report `ad0fb0b253d9fbf5b8c40b79ec2a4c142271be284c3570656b8325a7e9b92c54`, and independent compiled lock report `4cff6712198ba763550115d184030d25f69eeb46b414b2a5e73f229e05d2a7f8`. The primary compatibility revision is Cxbx-Reloaded `585c49a50af1255ab155099e06f24505f9c5a800`; the original API/layout declarations are retained alongside it. These references are compatibility evidence, not recovered original Xbox kernel instructions. The native implementation uses explicit fixed-width memory accesses and a host mutex rather than executing that compiled reference.

`research_physics_platform_lock_boundary_20261011.py` retains the actual owned executable's first heap-lock call without supplying any result: update 1.1 call `2DACAD`, return `2DACB3`, import ordinal 277, and critical-section address `08000610`. Its report hash is `ddbf22c6cf09518f34f55e4f0a1628e9a9804a0ec62bc12b312c984ef24973f7`. The exact 28-byte argument also appears in the independent compatibility oracle's inputs.

The new oracle executes the pinned compiled compatibility initializer and enter/leave functions, with separately supplied host atomics and opaque tokens verified from two distinct live host threads. Its 1,595 transitions cover three addresses, three initial dirty-byte patterns, both identities, recursion depths 1/2/8/32, the actual heap input, nine missing-wait and nine missing-wake boundaries, and unsigned underflow. It supplies no contended wait/wake result. The native test compares all 28 bytes and boundary identity for each transition. Native store observations must account for every change. It also checks missing current-thread ownership leaves memory untouched.

A separate native two-thread test supplies a host event service and verifies that the contender waits, recursive release does not wake it, outer release wakes it once, and the final source-visible lock is released. This is a test of the supplied native service contract. It does not validate original kernel wait lists, scheduling, Xbox hardware, or kernel register clobbers. The private source/input snapshots are not production resources.

The sealed physics initialization graph still stops before ordinal 277. Connecting these semantic platform operations to its full retained ABI requires separate caller/return-state evidence; this change deliberately does not invent that adapter. Process-heap/world/body ownership, live match integration, vehicle/ragdoll paths and all-map split-screen/LAN proof remain required by the active goal. No launcher or gameplay parity is established by these component checks.
