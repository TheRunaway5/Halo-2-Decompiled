# Process-heap reserve/commit boundary

The smallest real platform increment is a **retained reservation plus commitment of its first page**, with release of the retained reservation on the constructor's commit-failure path. The original game establishes the requests and how it consumes their output cells; it does not establish a Linux failure-to-NTSTATUS mapping. This continues the [renderer process-heap handoff](SHIELD_RENDERER_PROCESS_HEAP_HANDOFF.md). Research only: no original execution, supplied resource outcomes, implementation or test edits in this increment.
