# Owned-image looping and generic-construction operands

`OriginalData` now supplies optional `sound_looping_constants` and
`object_construction_operands` for authenticated Map Pack1.1 and u5English
executables. The base image remains absent because its corresponding source
operands have not been proved. No fallback values are supplied.

The looping provider imports the54 literal class names, pool name, empty
selector and dialogue selector from their resident executable bytes. The
54-pointer table is read to locate the owned strings; native strings exclude
the source terminating NUL. All114 original string fields across the two images
compare with an independent source-only export, including1244 original bytes
with terminators. The one and minimum-dB operands reuse the existing original
sound-create imports. The actual125E50/127210 allocator method addresses are
opaque selected-image identities; importing them does not execute or replace
their methods.

The construction provider reads exactly two bytes at1.1 `46FB64` or u5
`474C24`, not a widened four-byte read. The sentinel's low byte and full word
are the two measured operands in the complete B8A30/B9B70 construction owner.
Its one operand reuses the existing authenticated arithmetic import. The
export checks the two original instruction-reference packets and image hashes.

The new test includes both generic and type-construction headers. This also
checks their service types coexist after the generic service was renamed
`SourceGenericObjectConstructionServices`; no frozen type-dispatch interface
was changed.

Two independent original-only exports are byte-identical. The registered
production test passes with the normal build and actual GCC address/undefined
sanitizer flags. Copied build artifacts and shared source snapshots accompany
the reports; shared OriginalData/CMake files are observational snapshots rather
than immutable live-file pins.

No mutable engine gate, arena cursor, object pool, looping registration state,
class fade, listener, driver, source unit or world backing is imported. These
remain required owners. This data bridge does not establish successful native
grenade creation/release, audible reloads, complete startup, canister contacts
or all-map sound-event coverage. No launcher was changed by this checkpoint.
