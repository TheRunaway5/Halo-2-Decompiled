# Host continuation input state

The native port's `H2HOST05` sidecar retains the host input and motion-adoption state needed to resume the same host/local-player ownership. It preserves the completed ordinary, vehicle and death-camera banks and full native model metadata added by the preceding work. Older `H2HOST04` and earlier sidecars lack the current input state and reject explicitly. This is a native port envelope, not the Xbox System Link wire protocol.

The current production receiver consumes one accepted queued input per tick. A backlog larger than three drops its oldest entries; consuming one leaves at most two buffered entries. The continuation now retains the accepted pending entries themselves, including their held controls, input sequence, interpolation view time, quantized motion, pulse serials, completed interaction durations and vehicle intents. It also retains the newest accepted serial bank, consumed sequence/known flag, consumed motion reports, per-view report-step counts and input-consumption counters. The production buffering behavior is unchanged.

The host's `NonHostMotionAdopter` has an independent checkpoint. Its 41 exact configuration words and all 16 slot histories retain current unit/teleporter identity, last damage and impulse serials, observed velocity, correction budget, considered/forced sequences and forced-motion reason. Restoration validates every value and requires the fresh owner's configuration to match exactly before assigning the histories. The native motion writer remains bound to the new executor's actual World; callbacks and pointers do not cross the sidecar.

The missing owners produced a genuine continuation failure even when the complete native phase replay seal passed. In the recorded complete-snapshot layout, the first difference at byte 46 for a one-view peer was its consumed input sequence; byte 78 for a four-view peer was the first view's forced-motion sequence. These are private transport/adoption receipts, rather than camera or diagnostic timestamps. Restoring only native RAM and the older camera/pulse fields could not reproduce them.

[source_host_continuation_codec.cpp](../src/runtime/source_host_continuation_codec.cpp) encodes all fields explicitly. Its schema guards pin the aggregate extents. Decode and resume reject oversized/nonascending queues, stale or future queued sequences, inconsistent consumed/press ownership, absent-view motion, invalid interpolation markers, out-of-range signed-24-bit positions and malformed motion history. Capture/resume share the input-state validator. A rejected preparation publishes no host and does not install received motion into the native World.

The bounded checks are:

- [source_host_continuation_tests.cpp](../tests/source_host_continuation_tests.cpp): real native startup and peer admission, ordinary-eye warmup before queue creation, actual three-entry buffering, completed interaction delivered once, saved pulse backlog, canonical sidecar/malformed controls, exact model metadata after import, eight strict replay phases with complete packet equality and a final complete native-world seal. The current-source targeted result is [host-cut-input-ownership-probe.json](../build/test-results/player-shadows-20261028/host-cut-input-ownership-probe.json).
- [source_host_continuation_schema_tests.cpp](../tests/source_host_continuation_schema_tests.cpp): declared codec values only, including optional rank/ordinary-eye preservation, queued and consumed motion/serial/view/counter round trips, legacy revisions and malformed queued-input controls. See [host-cut-input-schema-probe.json](../build/test-results/player-shadows-20261028/host-cut-input-schema-probe.json).
- [nonhost_trajectory_tu15_tests.cpp](../tests/nonhost_trajectory_tu15_tests.cpp): uninterrupted/restored adoption decisions, retained budgets and forced histories, fresh writer ownership and atomic invalid-checkpoint controls. See [nonhost-motion-checkpoint.json](../build/test-results/player-shadows-20261028/nonhost-motion-checkpoint.json).

These checks use the complete-snapshot profile and authenticated logical-endpoint test adapter with the same host/local ownership. They do not establish default delta-stream ACK/baseline continuation, raw socket/WAN behavior, election, automatic migration or queued-input ownership when a remote controller becomes the new local host. The latter still needs its explicit local-controller bridge; this change does not claim that role transition is complete. The [final frozen 35-check cohort](../build/test-results/player-shadows-20261028/frozen-validation/cohort-v5-x11/report.json) passed the native continuation, 51 schema checks and motion-adoption regression; [bounded actual output receipts](../build/test-results/player-shadows-20261028/frozen-validation/cohort-v5-x11/test-output-receipts.json) retain their results. Targeted object-override probes remain separate evidence. Run CMake validation through [run_tests.py](../tools/run_tests.py) and probes through [run_test.py](../tools/run_test.py), retaining small reports and removing owned scratch as specified by [TEST_STORAGE.md](TEST_STORAGE.md).
