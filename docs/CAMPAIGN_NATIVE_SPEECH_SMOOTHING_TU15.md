# Native TU1.5 speech smoothing

Original `18F7A0` uses a typed semantic level update and thin ABI binding. It validates the object datum through the qualified generic `BCDF0(mask3)` owner, refreshes the pool/rows/body, reads real lower/upper operands, computes the clamped delta with COMISS/SUBSS, freshly reads the current level, and performs the original ADDSS/store at `18F804`.

The entry preserves complete original SIMD, x87 and MMX results, including fault prefixes, and owns the actual late return read/SP+4. GP mask `F8` is admitted for the actual `18F510` caller: EDX/ECX/EAX are unconditionally redefined at `18F5D4`/`18F5D8`/`18F5DF` before use. Both parents (`18ED80`, `18F490`) are authenticated; no general indirect-caller retirement claim is made. No SIMD register is retired.

Arithmetic EFLAGS have a separate caller proof. The unconditional `ADD EDX,EBP` at `18F5E3` defines CF/PF/AF/ZF/SF/OF before any post-smoothing flag use; only MOV/MOVSX instructions intervene after the smoothing call. `18F5E9` defines them again before the next call. The binding preserves non-arithmetic flags and leaves the ABI flags intact. The [original byte witnesses](../analysis/campaign-native-audio-20261030/speech-smoothing-candidate/flags-retirement.json) scope that retirement to the actual `18F510` continuation.

The original store is write-only. With an observer, `event.before` requires an additional four-byte read of the same level after ADDSS and before the write/its guards. It is qualified for stable committed ordinary RAM. Read side effects and topology races are not given original equivalence. A failing diagnostic read propagates before any write; it is an instrumentation fault, not an original read fault. Separate tests expose that third read, store rejection after it, and post-store observer failures. With no observer, there are only the two original level reads.
