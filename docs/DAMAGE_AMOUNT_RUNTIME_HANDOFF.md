## Exact player-scale ABI and real dispatch

`15F520` takes **ECX=full captured attacker player datum, EAX=resolved victim player datum**, returns the scalar in XMM0 and uses plain `RET`. EDI and the conditionally pushed ESI are restored; EBX/EBP are not modified by this body or the three recovered callbacks. **ECX is not unconditionally preserved.** Its entry `PUSH ECX` allocates the scalar local: `15F551 MOVSS [ESP+4],XMM0` overwrites that cell, and after ESI is pushed the same local is addressed at `+8`. Final `POP ECX` therefore consumes the retained scalar word. Only absent-engine/self branches before that store retain entry ECX. Attacker NONE returns ECX=`3F800000`; a rejected equal-membership strength2 request returns XMM0=0 but ECX=`3F000000`. [Complete `15F520`, especially `15F520..15F557`, `15F5A4`, `15F65B..15F669`](../analysis/damage-shields-goal-20261011/dispatcher-boundary/pairing/instructions/0015f520-old.asm).

A new bounded unchanged-original experiment records **18 cases across both images**, dirty GP/XMM inputs, full returned GP/flags/XMM/control/status/tag observations, and actual callback entry frames. It confirms the ECX local behavior, callee-saved registers, XMM1..7 preservation and the seeded x87 control/status/tag for these reached callbacks. The inputs reuse explicitly declared isolated Slayer/King/player/options stimuli; nearest-domain FP is configured by the existing original runner. This is not live player/engine admission, alternate rounding, or equivalence for arbitrary virtual callbacks. [Probe and exact scope](../analysis/damage-shields-goal-20261011/amount-boundary/probe-player-abi.py), [observations](../analysis/damage-shields-goal-20261011/amount-boundary/player-abi.json).

`1615F0` loads `*4F10B8`, engine index at `+C14`, and `566084[index]`. A nonnull object loads EAX=`[ECX]` and **JMPs** through vtable`+8C`. The current return address and two DWORD arguments are forwarded; this is a tail jump, not an extra call frame. `15F680` does the same through `+6C`. Both null branches execute `XOR AL,AL; RET8`, preserving EAX high24 rather than returning canonical DWORD0. Outgoing ECX is the selected object, EDX is its index, and EAX is its vtable before a nonnull tail. `15F520` passes full attacker/selector2, then full victim/selector3. [Trait dispatcher](../analysis/damage-shields-goal-20261011/amount-boundary/pairing/instructions/001615f0-old.asm), [membership dispatcher](../analysis/damage-shields-goal-20261011/amount-boundary/pairing/instructions/0015f680-old.asm).

## Exact campaign lower services

`12C740` takes **EDX=signed bit index, stack1=bitmap pointer**, returns canonical EAX0/1 and `RET4`. It uses low5 bits for the shift and arithmetic `SAR EDX,5` for the DWORD index; it has no local range check. ECX becomes the supplied bitmap pointer, EDX becomes that shifted index, and no SSE/x87 register is touched. `DB160` range-checks signed request`+10` to0..15, then queries index **designator*16+1** from `*4FCDC4+C4`. A true bit skips difficulty multiplication; a false bit admits it. Out-of-range designators other than NONE admit difficulty without this read. Request designator NONE or noncampaign options game type returns the retained amount. [Bit leaf](../analysis/damage-shields-goal-20261011/amount-boundary/pairing/instructions/0012c740-old.asm), [amount campaign branches `DB2DE..DB356`](../analysis/damage-shields-goal-20261011/dispatcher-boundary/pairing/instructions/000db160-old.asm).

`DB160` calls `1ED090` with stack DWORD0. This wrapper reads options`+08`; game type1 selects signed WORD difficulty`+132`, otherwise ECX=1. It **tails to `1ED030`**, which owns `RET4`. The table reader starts XMM0 from literal1.0, then reads `*4E791C` and its difficulty header`+F8/+FC`. Null globals, zero count or null pointer retain1.0. Count is tested for zero, not positive. CX is clamped0..3; the stack row selector is signed low16 with **no local row bounds check**. The addressed binary32 is `table + row*16 + difficulty*4`. The complete chain touches XMM0 and does not touch XMM1, preserving `DB160`'s live amount used immediately after the return. The admitted amount path writes the supplied output **byte1**; other paths leave it untouched. [Wrapper](../analysis/damage-shields-goal-20261011/amount-boundary/pairing/instructions/001ed090-old.asm), [table reader](../analysis/damage-shields-goal-20261011/amount-boundary/pairing/instructions/001ed030-old.asm).

Selected-image pointers are `4E791C→4ECC1C` for globals and `4FCDC4→5020C4` for relationships; the options/engine/player pointers and literal translations remain pinned in the enclosing report. Static zero pointer cells in an XBE are not initialized campaign state. Lockout globals `E1740000` has one difficulty block; row0's exact words are **`3DCCCCCD,3F333333,3F800000,3FC00000`** (0.1,0.7,1,1.5). Its raw header is `010000007c6c1480`, pointer`80146C7C`. This is authored row evidence, not a running campaign options/relationship producer. [Fresh raw fields](../analysis/damage-shields-goal-20261011/amount-boundary/authored-inputs.json).
