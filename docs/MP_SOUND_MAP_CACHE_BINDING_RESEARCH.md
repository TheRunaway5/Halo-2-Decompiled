# Original sound map reads through the owned cache

The production `SourceTagMetadataStore` now supplies a retained low16 table-slot address callback. It reads the actual disk tag table ordinal, verifies the selected resident payload's datum, group and address, and returns its literal address. Its explicit group set, missing-slot rejection and backing lifetime are covered by `owned_sound_map_metadata`. It selects no current map or default global datum.

The original Lockout map-start prefix's `matg` sound-global `+14` reference is **snmx**, the 88-byte sound mix payload at `8026F91C`. The separate 54-class data belongs to **sncl**. Earlier immutable map-owner fixtures use a local helper name `classes` for the referenced mix; their bytes, original instructions and calls remain unchanged. The new exporter retains complete snmx payloads without reinterpreting their interior: all 23 owned maps, 23 payloads and 2,024 exact bytes. Independent exports match (`fixtures.tsv` SHA-256 `86829296d44be7b9066b735d7e5671c9c44bc137ede992a708e42afd7d85d20e`; report `0b4dc072af0619e887dbc68c3971dc4568239be9d1934393c031d51ce7e86e28`). The previously retained matg/sncl/ugh payloads are separately preserved.

`owned_sound_map_cache_binding` composes the unchanged Lockout prefix with the actual owned `Cache`, explicit matg/sncl/snmx/ugh groups, real OS-backed `NativeSoundStorage`, and imported original map operands. The 143,360-byte startup arena and the measured clock value remain explicitly retained original inputs. Metadata reads and low16 tag lookups use zero fixture callbacks. No device or plugin callback is provided. Both supported operand images match the original 1.1 execution's 19 ordered writes, complete arena and globals, then stop at the genuine absent-driver read `2A0C` (4 bytes). Loading u5 operands is data correspondence, not execution of a u5 world.

Production GCC normal and ASan/UBSan runs pass all three registered checks: `owned_sound_mix_metadata`, `owned_sound_map_cache_binding` and `owned_sound_map_metadata`. These establish complete owned payloads, real cache lookup and the original CPU prefix with real retained arena backing. They do not establish successful original audio-driver initialization, cache readiness, source voice admission, live first-person reload routing, audible playback or sound effects on every map. The canonical launcher remains unchanged.
