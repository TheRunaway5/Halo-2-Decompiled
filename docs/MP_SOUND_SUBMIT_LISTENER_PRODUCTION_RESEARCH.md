## Submission

Its production comparison covers 2,574 cases and 196 ordered stores, including eight genuine optional-effect allocation, binding, rejection and release cycles. The semantic first-person event request is not zero-extended into that record.

Actual admission, promotion, source creation, effect update and first-reference seed producers remain required when their original branches reach them. Cold-path comparison is not successful reload admission.

## Listener

`sound_driver_listener.hpp/.cpp` ports complete `2228A0`/u5 `2271A0`, including its 56-byte caller input and pointed environment descriptors. Its platform requests preserve the original coordinate-word order `(x,z,y)` for position and both orientation vectors. The exact orientation/environment thresholds and complete 72-byte default environment are imported as raw immutable bytes.

The implementation retains the unspilled source 53-bit subtraction precision for threshold comparisons, signed count handling, original early comparisons, cache/dirty stores, forward overlapping DWORD copies and actual driver re-reads after platform operations. It does not clamp an invalid signed count into a fabricated zero-channel input. Real platform operations remain mandatory and unavailable backing stops.

The whole listener body and four remaining driver helper bodies are uniquely matched between the owned images: 516 rows per image. Independently repeated static reports and listings are byte-identical. The listener's unchanged original execution and repeated execution cover 128 cases, 2,286 ordered stores and 18,382,336 full output bytes. These include exact source thresholds, infinities/NaNs, signed count controls, pointed parameter/payload records and overlapping copies. The exporter independently reconstructs every whole original output and checks its SHA-256 before creating the native fixtures.

The original allocation-prefix input stops at its real native position request with no device supplied. In total, 66 comparisons stop at actual platform requests, 60 explicitly labelled raw-state controls return naturally, and two invalid-storage controls stop. Raw active/count/float controls do not establish successful source driver construction or live listener admission. No original platform return is supplied. Native comparisons use owned byte buffers; they do not exercise an allocator or physical audio hardware.
