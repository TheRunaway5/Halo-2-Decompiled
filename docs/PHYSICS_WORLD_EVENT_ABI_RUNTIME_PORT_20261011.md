They include contact event records and datum-pool operations, pose conversion, BSP and game callbacks, manager and agent retirement, island constraint accounting and removal, body deactivation, deferred retirement queues, and their required constructors and destructors. Production compiles C++ arithmetic, static calls and branches behind the preserved GP/SSE/x87 caller ABI; it contains no opcode decoder, original executable execution, or checkpoint replay. Other required lower owners remain explicit.
