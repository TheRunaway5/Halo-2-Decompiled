## Exact capsule and item-point producers

`C57A0(unit EDI,item ESI)` starts with trueAL. Its geometric branch runs only for unit header type mask1 and target header type mask`1C`; other admitted object types retain source true return. Its caller owns valid object resolution. [Type gate](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000c57a0.asm).

`E0C20` first resolves the unit world root through `BACC0`. If biped physics bit0 is clear, add metadata radius to bottom.z; otherwise retain the root. Physics bit1 selects sphere mode: extent0, radius unchanged. Otherwise extent is separately rounded **`(crouching-standing)*unit.crouch + standing - 2*radius`**, and top is bottom with extent added to z. Object query sphere radius/center and camera height do not enter this formula. Stock Lockout metadata is flags4, standing0.725, crouching0.5, radius0.175; the frozen original executions use crouch0. Native `capsule_segment_height` represents the scalar formula but does not supply the root/bottom flag handling or its producer. [E0C20](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000e0c20.asm), [native scalar](../src/kernels.cpp), [metadata import](../src/content.cpp).

`FBFA0` chooses the actual item interaction point. With item flag`+12C bit5` clear, use original `BACC0`. With that flag set, query actual render-model marker **`0C0000C1 ground_point`** through `B9C20→1DC8F0/1DC940`; AX0 falls back to `BACC0`. Successful ordinary contact (`+132 == FFFF`) reads surface`+134` from the current collision bank, obtains its signed plane via `14BA50`, and projects the actual world marker to plane offset **`0.05`**. Ordered distance arithmetic is z product + y product + x product − plane distance; xyz output is marker + normal×(0.05−distance), with original separate rounding. The instanced-contact branch remains outside the frozen live scope. [FBFA0](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000fbfa0.asm), [marker and plane output](MP_PICKUP_VISIBILITY_RESEARCH.md#original-contact-point-producer-conditional-physics-boundary).

A zero marker ID/root fallback is source-defined in specific attachment calls; it is not permission to treat unavailable `ground_point` metadata or an unavailable current node bank as a successful zero-marker query. Preserve availability/failure distinctions. `Body::grounded` and a BVH support normal cannot set item contact bit5 or manufacture `+134`. [Marker lookup/output contract](MP_WEAPON_ATTACHMENT_RESEARCH.md#actual-cache-records-and-marker-contracts), [native host solver](../include/halo2/collision.hpp).

## Outer normal offset and retreat

Only a hit and mask bit`20000000` admit correction. Therefore the visibility rays`14800001` do not run it; target-side clips`24800001` can. For ordinary terrain, if the recorded final leaf is valid, classify the formed hit point and compare leaf identity. A disagreement reaches normal offset. A recorded final leafNONE bypasses this leaf-comparison correction in the original ordinary path; do not invent unconditional hit-point nudging. [Gate/classification](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/0016b240.asm).

Normal offset adds oriented normal×**`39800000`**(0.000244140625) to the formed point, then executes the source locator into final location. It preserves the fraction. If the corrected leaf is valid, ordinary terrain returns. If leafNONE, compute the ordered float32 segment-normal dot z+y+x; for the executed nonzero-dot path the original x87 division rounds **epsilon/abs(dot)** into the float32 constant retreat step. [83 frozen normal corrections](MP_PICKUP_VISIBILITY_RESEARCH.md#executed-endpoint-correction-and-coverage-limit), [retreat setup/iterations](MP_PICKUP_RETREAT_RESEARCH.md#retreat-ownership-and-per-iteration-contract).

Each retreat iteration subtracts that same step from the current fraction, clamps nonpositive to0, recomputes point from original start/delta/new fraction, then relocalizes. Positive fraction with leafNONE repeats; positive fraction with a valid ordinary leaf returns. Zero fraction returns even with leafNONE. There is no recovered fixed iteration cap: the actual edge399 probe required **1,454** iterations, and edge1101 required **549**. Source contact type/identity/plane remain intact while outer fraction/point/final location change. [2,122 independently audited iterations](MP_PICKUP_RETREAT_RESEARCH.md#executed-outcomes), [per-iteration audit](../tools/oracle_mp_pickup_retreat_audit_1_1.py).

Keep three distinct facts: **segment hit**, **final location validity**, and **C57A0 visibility return**. Vertex188 proves hitAL1/fraction0/final leafNONE. The target-side `C57A0` consumer still copies the returned point on hit; it does not require a valid final leaf before doing that store. No caller may silently reinterpret this as a clear segment or manufacture a leaf. [Source endpoint storesC5B4F–C5B6C/C5B91–C5BAE](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/000c57a0.asm), [zero-clamp evidence](MP_PICKUP_RETREAT_RESEARCH.md#executed-outcomes).

The source zero-dot step`3D000000`(0.03125), unordered-input behavior and additional instanced/object collision-BSP validity checks are statically present but remain outside executed retreat coverage. Ordinary `&E==0` native admission must not claim those branches' parity. Preserve separate float32 operations rather than fusing multiply/add or replacing source comparison/division paths with unrelated vector helpers. [Unexecuted limits](MP_PICKUP_RETREAT_RESEARCH.md#audit-reproduction-and-remaining-scope), [existing native contraction policy](../CMakeLists.txt).
