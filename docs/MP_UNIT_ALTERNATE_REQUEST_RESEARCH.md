# Retained alternate animation request owner

The new `unit_alternate_request` module implements complete original `1DF670` and its complete `1CFA90` availability caller. It closes the alternate lookup required by the frozen `1CEC20` channel owner. Seven naturally positive original requests agree with native output and resource-call order. This is an isolated request/storage dependency, not live grenade gameplay, resource residency, or current-transform sampling.

The immutable scope is `analysis/multiplayer/integration/spawn-source/unit-alternate-request`. Prior caller, channel, transition, constructor/action, resource and release freezes remain unchanged. Production changes are new header/module/test and a localized CMake stanza only; there are no Unit, Simulation, runtime, frontend, renderer, shader or release edits.

## Complete bodies and data contract

The complete 1,007-instruction `1DF670` body differs from the frozen complete `1DEB60` body at exactly one instruction: `1DEBE4 add eax,4` becomes `1DF6F4 add eax,0xC`. Internal branch targets correlate by complete instruction row; external call targets and all other instruction semantics agree. The independent `body-delta-proof.json` retains both raw listings and the sole difference. The new implementation uses the alternate action bank at weapon+0C, preserving fallback traversal, inheritance, optional resolved outputs, resource demands and the exact final packed-output store sites.

`lookup_source_alternate_animation_request(graph_address, identifiers, packed, optional_resolved, graph_memory, resource_services, observer)` requires literal owned graph metadata and real lower resource owners. Identifiers are mode, class, weapon and activity. `packed` is at least four writable bytes; each optional resolved output is absent exactly when its source pointer is NULL, otherwise at least four bytes. Class NONE writes packed NONE and leaves optional outputs untouched. Packed high16 != FFFF is the original success predicate. The original returns its caller-provided packed pointer in EAX; the exporter checks this for every actual call. The native void API exposes that same caller-owned output span without inventing a guest address.

The lookup retains all five unconditional resource-bank sweeps for both requested and resolved identifiers, including repeated equal tuples and the authored fallback key `030000D9`. Signed bank counts, x86 address arithmetic, descriptor+10 admission and inherited graph requests are preserved. Bounded host resolvers reject missing or escaped storage. No missing graph, request, resource, allocation or IO owner is replaced by successful or NONE return values.

`source_unit_alternate_animation_available(manager, graph_memory, resource_services, observer)` implements complete `1CFA90`. It resolves graph datum manager+68 once, then tries activities `0E000044`, `0E000045`, `0B000046` in that order. Manager+70/+74/+78 are read again before each call, preserving possible lower-owner mutations. It returns true at the first valid packed result. Its private output is scratch, not a supplied Unit field. This caller checks availability only; it does not sample root/current transforms, install a channel or establish resource IO success.
