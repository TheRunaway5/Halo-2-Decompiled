# Native campaign speech retirement follow-up

The semantic module closes complete `215B40` actor channel publication through
the real `1110D0` unit-state owner, and complete `1494F0` live-clock conversion.
These are required children of speech retirement `215840`. The typed algorithms
read and write actual object/actor state and perform native SSE or hardware
extended arithmetic. They use no virtual CPU, instruction dispatcher, supplied
backend result or original outcome replay.

The public API is `include/halo2/native_campaign_ai_speech_followup_tu15.hpp`.
`cmake/CampaignNativeAiSpeechFollowup.cmake` adds the semantic source and its
original-reference test. It does not enable a whole campaign group or live
speech route.

`1110D0` resolves the unit body through the real object header bank and reads its
signed `+33E` state offset. A `FFFF` high word at state `+5C` returns without
touching FP or channel data. Other states preserve the source's exact signed
channel policy, including negative channels other than `-1`. A positive duration
reads the actual signed clock rate and publishes the reciprocal scaled delay.
The nonpositive or unordered path clears thirteen bytes in order, rereads the
published target, multiplies by the original255 constant and performs the
source's truncation/unsigned saturation before its indexed byte publication.
Negative and invalid converted values saturate to255, matching the original.

`215B40` captures the real actor row before rejecting channels outside0..12.
For a valid channel it reads the actor's unit, loads the original target1
constant, invokes the complete native unit owner with duration0.5, then writes
the supplied low16 timer to actor `+6CE`. The actor row is retained across the
unit operation. An alias case overlaps that final timer with the unit's inverse
blend field, proving the publication order.

`1494F0` reads the live clock owner and signed tick rate, converts and multiplies
in single precision, then uses the actual extended `FISTP` control-word rounding.
It requires one available extended temporary. The unit and actor operations use
only SIMD and support all eight extended slots occupied. Returned effect values
describe the actual scalar results for thin ABI transport; they do not implement
the algorithms through register state.

The offline proof executes unchanged SHA-256 pinned TU1.5 instructions in real
i386 processes. It compares all retained banks, each ordered read and preceding
store count, every store's before/after bytes, actual SIMD outcomes, FP control
and status, occupied extended values and the preserved caller registers.
There are298 original calls,1,574 engine reads,2,176 stores and19,569 original
callee instructions. Seven controls reject changing channel13 admission,
negative channel handling, the final clear byte, invalid-byte saturation,
timer publication, `FISTP` rounding and moving a target read before preceding
stores.

All95 reachable sites are covered. The remaining site `111181` is the original
OR-FF branch after converting a private local which `111162` just overwrote with
zero. Its unsigned0..255 comparison always branches past that OR. This proof's
retained unit state is disjoint from actual private argument storage; that
domain is part of the typed by-value caller contract.

Three caller receipts execute the actual `215840` block at `215B06`, naturally
reach `215B23 -> 215B40`, and return to `215B28`. They capture the actual actor,
channel and wrapped WORD timer, including channel13 rejection. The preceding
retirement/dispatch calls are not executed by those bounded block receipts.

Evidence is under `analysis/campaign-native-speech-followup-20261028/`.
Unmapped input faults, unmasked FP traps and missing extended capacity for the
conversion are outside this matrix. Whole `215840`, its genuine `203D80`
dispatch, `116D60/117240` submission, `213D30` dispatch, `214710` scoring and
the full request-`0x34` cancellation composition remain open.
