The retained minimal memory banks expose that defect and verify the correction. Original reciprocal-square-root estimates and timestamp reads still require explicit services.

Both builds run the new fixtures and the retained world/contact/manager boundaries. The validator records exact source, fixture, binary and log hashes, repeatability, coverage and the next required owner.
