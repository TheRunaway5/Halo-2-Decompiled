# Original ordinary-terrain outer query and locator fixtures

The independent [exporter](../tools/export_mp_pickup_outer_fixtures_1_1.py) packages **1,787 original outer queries**: every one of the frozen visibility suite's **1,763** observations and the separate retreat suite's **24 case-indexed probes**, retaining **all 2,122 retreat iterations**. Runtime expectations are copied or byte-decoded from the pinned original reports. The exporter never runs native code, a replacement collision/classifier implementation, or a new emulator execution. Actual cache blocks are exported as source inputs. Both earlier suites and every previous report/tool remain unchanged. [Visibility authority](MP_PICKUP_VISIBILITY_RESEARCH.md), [retreat authority](MP_PICKUP_RETREAT_RESEARCH.md), [composition contract](MP_PICKUP_NATIVE_CONTRACT.md).

The ordinary-terrain kernel scope is **1,785 queries**. Exported query IDs **1503 and 1504** are the visibility report's two mask`24909C0D` first-item motion casts, conditional on its explicitly supplied unavailable Havok service. They remain in the complete export with `ordinary_mask_scope=0`; they do not support an ordinary-only comparison claim. The other records have `(mask & E)==0` and require no active object-ray/Havok branch for their exact supplied segment inputs. Some segment origins came from the separately stated pose/contact fixture boundaries; kernel comparisons do not close those live producers. [Conditional first-item/contact producer](MP_PICKUP_VISIBILITY_RESEARCH.md), [ordinary-query admission](MP_PICKUP_NATIVE_CONTRACT.md).

## Compact record schema

All float32 values are their exact eight-digit hexadecimal words. Masks, addresses and original raw root/leaf returns also use hexadecimal; counts and ordinary indices use decimal. `B` descriptor offset and `P` signed plane are hexadecimal. Raw location/record strings are **little-endian bytes**, not hexadecimal integers. `-` means unavailable. The machine-readable schema lists each field's encoding and complete order. [Schema](../analysis/multiplayer/integration/inventory-source/pickup-outer-fixtures/schema.json).

| Tag | Count | Contents |
|---|---:|---|
| `I` |1| Active BSP index, sbsp/metadata magic, root/collision pointers and file offsets, collision/material/leaf-cluster counts. |
| `B` |10| Eight collision blocks plus root collision-material and leaf-cluster blocks: descriptor offset, stride, count, pointer, file offset, raw SHA. Descriptor owner is explicit in `cache-import.json`. |
| `M` |19| Source collision-material index → signed global material. |
| `J` |2313| Source leaf index → signed cluster. No sorting or compaction. |
| `Q` |1787| Export/report identity, mask scope, caller/mask/excluded datums, start/delta bits, returnAL, type/fraction/point, initial/final location8, defined-byte mask and full captured outer`5C` bytes. |
| `K` |1787| Same query ID; lower flags/BSP/root/range/best/breakable input, hitAL, initial/final prior leaf/class/plane, visited count/order, hit-only lower`18` bytes and both raw`28` descriptors. |
| `S` |18672| Same query ID; ordered original instruction snapshot, source stream/index, iteration, point validity, fraction/point/location8 and available original normal/stack/XMM words. |
| `R` |2122| Same query ID; iteration and four `S` indices, captured step, before/after fraction, point and final location8. No computed expectations. |
| `C` |2645| Original `14B9D0` root/BSP/point and returned leaf. |
| `L` |2364| Original `11D4A0` point, active BSP, returnEAX and location8 bytes. |
| `P` |3| Original `14BA50` collision BSP/signed plane and oriented plane4f bytes. |

`Q/K/S/R` IDs address the exported query sequence: visibility indices0..1762, then retreat cases in their original case order. `C/L/P` IDs address a separate combined original-call sequence. Those point/plane fixtures include all captured constructor and contextual calls from both frozen reports, including calls surrounding the retreat report's eight source-C57A0 casts which are not duplicated as exported `Q` records. Repeated points and calls remain repeated. The report indices in every record/provenance file provide an exact lookup. No internal per-node distance/branch snapshots were captured in these frozen reports; this export preserves exact routine returns and raw nodes/planes without synthesizing those intermediate outputs. ## Defined output and iteration rules

Compare `Q` only where its **92-byte `defined_byte_mask` contains FF**. Type/fraction/formed point/location bytes`00..23` and initialized NONE identity bytes`38..43` are defined on both hit and clear. Global material`24..25`, oriented plane`28..37` and lower contact fields`4C..5B` are defined on terrain hits. Padding`26..27`, unknown/inactive bytes`44..4B`, and clear-cast hit fields remain captured provenance, not expectations. A clear `K` uses `-` for the unavailable lower hit record. Only the explicitly decoded descriptor prior leaf/class/plane fields are comparison inputs/outputs; descriptor padding and emulator pointers do not become native state requirements. ReturnAL is compared independently from location validity. [Original initialization/contact stores](../analysis/multiplayer/integration/inventory-source/pickup-visibility/instructions/0016b240.asm), [lower layout](MP_PICKUP_SPATIAL_RESEARCH.md).

The lower hit`18` bytes encode fraction`+0`, selected source plane pointer`+4`, leaf/surface/signed-plane i32`+8/+C/+10`, surface flags/breakable bytes`+14/+15`, and BSP material i16`+16`. A native crossing-plane index must be compared against **the decoded source pointer** relative to the exported cache plane-array address/stride; it is not necessarily the signed surface-plane identity. Preserve lower fraction and visited-leaf order when outer correction changes fraction/location. The exact query root0/range[0,1], initial best`7F7FFFFF`, prior leaf/planeNONE, prior class0 and lower flags`29/9` are separate exported fields. Breakable count256 uses eight FF words from the pinned original full-reset fragment's observed intact fill; its supplied storage and excluded surrounding lifecycle remain explicit. [Lower source contract](MP_PICKUP_SPATIAL_RESEARCH.md), [reset fixture assertion](../tools/oracle_mp_inventory_spatial_1_1.py).

Every `S` observation precedes its named original instruction. At`16B89E`, the point is stale and `point_defined=0`. The point is formed by`16B8EB`. Retreat query snapshots merge the two original hooks only where their overlapping fields are byte-identical: the richer `retreat_trace` is retained, plus the pre-formation snapshot from `correction_steps`. `S.source_stream` is `C` for `correction_steps`, `R` for `retreat_trace`; it is not the iteration-record tag. Captured normal/stack/XMM fields are only meaningful at their owning source stage; they are never default numerical inputs. [Original hooks](../tools/oracle_mp_pickup_visibility_1_1.py), [rich retreat hooks](../tools/oracle_mp_pickup_retreat_1_1.py).

Each `R` joins `16BA30` before subtraction, `16BA4D` after fraction store, `16BA80` after point formation/before location, and `16BA85` after original locator return. `S/R` inherit the exact original caller/mask/start/delta and initial query identity from their `Q` record. The `S` stream retains every captured loop/exit snapshot. Iteration numbers are zero-based and are `-1` before the first retreat iteration. There are **107 normal-offset paths**, comprising 83 frozen mask-replay corrections plus 24 explicit retreat probes. There are **12 zero clamps**, including vertex188's fraction0/locationNONE exit; the remaining 12 probes exit with positive fractions and valid leaves. Edge399 takes 1454 iterations and edge1101 takes 549; no source iteration cap is inferred. [Retreat execution](MP_PICKUP_RETREAT_RESEARCH.md), [original correction/loop instructions](../analysis/multiplayer/integration/inventory-source/pickup-retreat/instructions/0016b240.asm).

## Minimum comparison scope and retained producers

The isolated native target can import these actual packed collision/leaf/material records, take each ordinary `Q` start/delta/mask and explicit intact breakable input, preserve lower `K`, build defined outer contact/location fields, then compare normal correction/retreat snapshots and independent locator results. This closes a bounded **outer ordinary-terrain kernel** gate. It does not authorize replacing a live source segment/point/normal/contact with host BVH or guessed physics output. [Minimum composition contract](MP_PICKUP_NATIVE_CONTRACT.md).

Full source object allocation/equipped current-node production, native registry/broadphase ordering, active instanced/object winners, original Havok item motion/settling and dropped trajectories remain separate integration gates. The two conditional casts and subsequent conditional contact/pose origins retain their original boundaries. The rich probes execute the nonzero-dot ordinary-terrain retreat branch; zero-dot/unordered inputs and additional collision-BSP retreat branches remain unexecuted. Exact Xbox `RCPSS/RSQRTPS` behavior remains unresolved for the source pose fixture. No new default transform, motion model, contact service or production implementation is supplied by this export.
