# Retained animation selection and literal graph lookup

The new [native selector](../src/unit_animation_selection.cpp) implements the complete direct `1D0A60` owner, its complete three-channel reset `1D0590`, channel installer `1C9E60`, installation wrapper `1CEE00`, and the original validity/authored-flag gates. The pure `1E0F50`, `1DEB10`, `1CFCE0` and `29C6A0` owners operate on literal imported graph records. **33 complete manager cases, 42 explicit required service boundaries, 1,636 ordered writes and 729 pure lookup cases pass.** The actual Cache-owned payload mode also passes those cases. This does not complete the remaining graph/resource/variant/action producers or enable live switch/melee/grenade gameplay.

## Native contract

[The public interface](../include/halo2/unit_animation_selection.hpp) accepts an existing source-owned `0x90` manager. `selection_flags` is the fourth original stack argument and `installation_flags` is the fifth; neither replaces the other. The activity is original EAX. `1CFDE0` produces both a normalized **requested** tuple and the **resolved** tuple found by fallback. The primary channel receives resolved activity, while manager `70..7F` receives the requested tuple. For the SMG, those tuples can differ in mode/class/weapon or activity; a selected idle clip cannot replace the owner.

`1D0590` resets only the three 32-byte channels and retains `60..8F`. Full `1CE9B0` cannot replace it. `1C9E60` preserves original write widths/order, flags, two low-byte fields and signed-byte-to-signed-word conversion. Failed graph/packed admission writes nothing. The selector preserves early-failure/flag4 identifier updates, primary-install failure, secondary/third gates, authored-flag checks, changed-identifier resource scheduling and final channel flags. Missing required services throw at the actual boundary after preceding owning stores; there is no fallback success.

Original SSE operations remain separate single-precision operations with contraction/fast-math disabled. The imported words are:

| Use | TU1.1 VA | TU1.5 VA | Literal bits |
|---|---:|---:|---:|
| Source one | `465030` | `46A0D0` | `3F800000` |
| Source comparison zero | `465048` | `46A0E8` | `00000000` |
| Frame subtractor | `46504C` | `46A0EC` | `38D1B717` |

The frame subtractor is the original small epsilon, **not a one-frame subtraction**. Production code accepts exact executable-imported words and contains no tuning payload default. The nine measured selectors cover actual default/equip/bind requests; they do not establish every possible positive frame-retention, secondary-install or root-transform branch. The complete bodies are retained and the remaining required producers remain explicit.

## Actual graph data linkage

`SourceAnimationGraphMemory` resolves a datum to its actual original metadata VA and resolves bounded byte spans at those opaque VA tokens. It never dereferences an Xbox address as a host pointer. The complete authored graph payload supplied by `Cache::load_source_unit_animation_graph_metadata` satisfies this contract; callers must retain ownership and reject absent or escaped backing. The Cache packet API retains the full `jmad` payload, header `0xC4`, count/order/stride/pointer words, and all nested banks.

The pure owners use the original signed binary-search comparisons and exact bank order: graph `+34` mode records stride `14`, nested class records stride `14`, weapon records stride `34`, action records stride8, and graph `+54` weapon-to-class mappings stride8. Request current/default StringID substitutions and fallback iterator counters/preserved outputs follow the original instructions. No named animation, sorting, missing-key fallback or fabricated inherited graph is introduced.

Every measured header/record span from all sixteen lookup banks lies within exactly one actual owning graph extent and equals literal authored cache bytes. No measured lookup escapes into another graph/shared backing. Optional actual-Cache validation imports all **58 graphs**, compares **89 retained spans**, repeats all **729 pure cases**, and repeats all **33 manager cases** using **three stable Cache-imported definitions**. Definition lifetime is retained by owned map entries keyed by full graph datum and packed word, not by a temporary return object. Cache source import and the earlier complete definition-event-array validation remain separate lower-owner evidence.
