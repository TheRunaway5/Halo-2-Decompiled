# Shield presentation and player damage audio

Current integration, 2026-10-12. This supersedes the native integration gaps in the frozen [shield graph research](SHIELD_BREAK_RECHARGE_LIVE_RESEARCH.md), while preserving that document's original evidence and remaining reference boundaries.

The actual multiplayer game loop now consumes ordered damage/depletion/recharge requests from shared `Simulation`, keyed by full object lifetime handles. Effects use the accepted body pose and authored root/body/head/shield_recharge markers. They advance once per accepted game tick, including received LAN ticks. Rendering another local view does not consume the event again. Respawns receive a new handle. Damage shaders remain on character body and complete first-person character models, including arms, hands and fingers; held weapons do not receive the shield material.

Attached effects support the authored coordinate systems, class7/8/9 sprites, and class1 PRTM recharge geometry. The recharge mesh retains its 172 authored vertices, 504 triangle indices, actual declaration and original vertex program. PRTM transformations follow retail224FD0; original creation flags select the initial event advance. The authored cull state is mapped using the pipeline's actual front-face convention.

HUD sounds come from `hudg+418`, using original13A720 state bits,13A838 retained shield value, and22BEB5 impulse/loop admission. Both species use shield-hit sound `E8170692`. Spartan charge/low/empty tracks are `E8190694/E81D0698/E821069C`; Elite tracks are `E81B0696/E81F069A/E823069E`. Authored gains and Elite recharge's .1-second fade are retained. The fade uses the existing12A810 curve and sound clock, including its relative-time endpoint convention.

The report journal preserves these operands over native LAN protocol51. Original options mode+0C is kept distinct from game type+08. The standalone native player adapter uses the ordinary mode branch; original distributed-client/campaign actor/scripted dialogue owners are separate contracts. Some authored pain choices are NONE; the adapter preserves that silence. Spartan pain/death PCM resolves to `E96D07E8/E96B07E6`, Elite to `EA93090E/EA91090C`.

The split-screen crash after loading was traced from the native core to `NativeUnitDamageAudio::hud`. Before the first player-birth tick, the prepared world correctly supplies `NONE`. That matched the default HUD handle, bypassing initialization of its authored sound slots; the subsequent sound-state loop indexed an empty vector. New HUD entries now initialize their slots regardless of handle equality. This preserves the genuine absent-unit interval and keeps game audio enabled. The two-view audio regression reproduced the original segmentation fault before the fix and now passes absent unit, birth, shield break, removal and salted-handle respawn.
