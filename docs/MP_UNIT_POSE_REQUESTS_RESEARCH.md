# Retained unit pose-request owners

The new `unit_pose_requests` module implements complete original `114BD0`, `1CF4C0`, `1CF3C0`, `1CF360`, `1CEF10`, `1CFB90` and `115AF0`. It composes the frozen alternate lookup, request resolver and channel installer using actual retained body/header/manager storage. Native comparisons agree with 63 unchanged original owning calls, 273 stores and 498 call boundaries. This closes the constructor's pose-request dependency; it does not establish live resource activation, world pose sampling, the complete generic Unit constructor or Q gameplay.

The immutable scope is `analysis/multiplayer/integration/spawn-source/unit-pose-requests`. Edits are new header/module/test/tools/document plus one localized CMake source/test stanza. Prior evidence and Unit, Simulation, runtime, frontend, renderer, shader and release files remain unchanged.

## Complete owners and required inputs

`update_source_unit_pose_requests(unit, objects, services, calls, stores)` implements complete `114BD0`. It reads the actual low16 header slot, its body pointer and extent, and the signed body+12A manager and body+33E extension offsets. It preserves the source's computed manager-address zero gate and adds no salt predicate absent from this body. Storage must come from its owning allocator/constructor; offsets are read from retained source state, not supplied as constants. The caller snapshots extension+98 and manager+74/+78/+7C before its first lower call.

The complete activity dispatch selects `0C000026`/`0E000028`, `0B000027`/`0D000029`, or NONE/NONE using the original comparisons, compact byte table and jump table. Activities `0400004A` and `05000049` require body+14 NONE for the first group. The dual-class `0400054B` branch and ordinary branch retain different writes and widths: ordinary writes four signed-short NONE values at extension+104/+106/+108/+10A, while the dual branch writes packed requests. Stores to +FC/+100/+114 precede those branch stores; `115AF0` precedes the three `1CFB90` calls and stores to +118/+11C/+120. The extension flag bit2 is set from the actual packed high16 validity predicates. The measured ordinary cases exercise the ordinary branch and first activity group; other complete source branches are implemented but not claimed as additional executed fixtures.

`lookup_source_unit_pose_request` implements `1CF4C0`: normalize current class/weapon sentinels, try the alternate channel-backed owner first, then use actual request-resolution fallback. `lookup_source_unit_alternate_pose` implements `1CF3C0`, including all 32 bytes of its private source-initialized scratch channel and complete `1CEF10` with flags0. `construct_source_unit_pose_channel` exposes that exact initializer; its only immutable float input is the imported one word. It does not initialize a Unit body or manufacture a selected clip. `lookup_source_unit_resolved_pose` implements `1CF360`, calling complete `1CFDE0` with mode manager+70 and flags0. Its private requested/resolved buffers are host scratch; source owners write their complete 16-byte contents before consumption. Host initialization of this scratch is not a supplied gameplay input.

`install_source_unit_alternate_pose_channel` implements `1CEF10`: current-sentinel normalization, complete `1DF670` alternate lookup and `1CEE00` channel installation. `lookup_source_unit_pose_index` implements `1CFB90`, including graph lookup before the index gates, and index0/1/2 activities `0E000044`, `0E000045`, `0B000046`. Other indices return the source packed NONE. `update_source_unit_posture_channel` implements `115AF0`: actual body/manager/extension lookup, activity `10000551`, then complete channel installation with flags803F, byte arguments FF/FF and type1; only actual success clears extension byte80.

Graph payload, definition, request/resource, variant and frame-clamp owners remain explicit services. Missing required providers throw; they are not replaced by successful or NONE defaults. The measured pose chain calls no variant or frame-clamp descendant, so these callbacks are deliberately unavailable in the comparison. Original packed-pointer EAX returns are checked by the exporter. Native caller-owned spans avoid inventing guest pointers; bool outputs compare defined AL, and the void `115AF0` observer records a return boundary with no fabricated result.
