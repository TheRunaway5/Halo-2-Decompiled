# Native TU1.5 simplex triangle orientation

The semantic `30D3F0` kernel passes 32 complete physical comparisons per
compiler and rejects three mutations. The [qualified report](../analysis/physics/native-simplex-triangle-tu15-20261101-qualified/report.json)
and [aggregate](../analysis/physics/native-simplex-triangle-tu15-20261101-qualified/aggregate.json)
retain the original authority, exact commands/source hashes and each result.

All 137 authenticated sites become native vector arithmetic, comparisons,
normal orientation and paired vertex/weight publication. Inputs are the
current simplex DATA, point, triangle vertices, orientation policy and FP
context. The native function returns the actual typed three-bit region mask.
It has no dependency service, register-file interface, opcode stream or
supplied original result.

Four actual original solver entries reach this helper in the protected
Gemini/Elongation cohort. Eight states each exercise unchanged input, positive
and negative orientation, disabled orientation, outside-triangle coordinates,
signaling/quiet NaNs and tiny values under FTZ/DAZ and different rounding.
Both compilers match 2,887,021,344 persistent bytes, the complete 368-byte
simplex DATA packet, return mask and FP words across 3,600 original
instructions and 392 strict ordered operand events. Eight normal flips are
observed; masks 1/3/6/7 are reached. Weight sign, missing orientation and
truncated region-mask mutations are all rejected.

The [local caller audit](../analysis/physics/native-simplex-triangle-caller-context-tu15-20261101-first/report.json)
starts at the actual `30EB8A` and `30ECE7` return boundaries with only the
typed EAX mask, preserved EBX/EBP/ESI/EDI and ordinary ESP available. No
volatile ECX/EDX or XMM lane is consumed before a fresh local definition.
Calls remain explicit transitive boundaries in that source audit.

The later [composed full-root report](../analysis/physics/native-simplex-helpers-full-return-tu15-20261101-staged/report.json)
and [aggregate](../analysis/physics/native-simplex-helpers-full-return-tu15-20261101-staged/aggregate.json)
run native triangle and closest-segment helpers together inside every genuine
original caller through `1CCACA`. All 28 roots per compiler match their
2,530,428,092 persistent bytes and FP/preserved root ABI, including all opaque
contact bytes. Every one of the 73 typed helper-return DATA/mask/FP stages
also matches. Of 62 triangle calls, observed return sites are `30EB8A`,
`30ECE7`, `30DADE` and `30E3BB`; the latter two belong to genuine `30D830`
and `30DE60` parents. Thirty-eight helper calls independently poison volatile
GP/SIMD/arithmetic flags after publishing only typed EAX and normal RET.
No original postimages are supplied. The region-mask mutation is rejected at
its strict typed return, even when the final caller discards the temporary.
The earlier final-only weight control is retained RED because that selected
case did not expose its change at final root return. No raw byte is waived.
