The smallest existing source seam is **`source_update_biped_prephysics_1_1` → required `E5700`/`E4D30`**, over its retained source object/physical bank. Those two leaves are not currently implemented or joined. ## Exact producing state and ABI

`E4D30` takes the full object datum in **EAX**, preserves EBX/EBP/ESI/EDI, and ends in plain `RET`; caller ESP therefore advances by4. It resolves object-header pool `*4E78D0`, headers at pool+44, stride12/body pointer+8; tags through `*4EB114`, stride16/pointer+8; damage globals through `*4E791C`+144; options through `*4EDF18`. The early options DWORD+8 equal2 returns without sampling velocity. These are current owned pointers/bytes, not serialized zero globals. [TU1.1 complete body](../analysis/multiplayer/integration/scope-camera/ordering-measured/instructions/000e4d30-disc-000e4d30.asm#L1).

The actual scalar and gates, in source order, are:

1. Cache immunity from object DWORD+134 bit9, biped definition DWORD+1F0 bit2, or object byte+10A bit7. This suppresses the damage subbranch; it does not replace the rest of the owner.
2. `BB0C0`: EAX=datum, ECX=caller 12-byte linear-velocity output, stack argument0=null angular output, `RET4`. It follows parents to the root, uses a valid physical component/body's actual velocity via `1D43C0`, and otherwise reads root object+88. A body+ C1 bit0 path yields the selected zero-vector literal. Native `Body.velocity` is not this whole resolver.
3. If object word+348 bit11 is set, `DEF10` receives **EDI=datum** and stack argument=scalar-output pointer, `RET4`; AL nonzero subtracts that output. Its original body derives the scalar from source buoyancy/gravity fraction, authored biped+268/+26C and clock signed16+2, admitted by definition+264 bit1 and `E5680`/`E23F0`/nonzero fraction.
4. `10DF90(datum, velocity_output, 0)`, `RET0C`: AL nonzero subtracts its output Z. This follows root parents, checks root word+C0 bits1/2, and on admission searches current `*517FE0` motion/support bank: count+1D80, full-object identifiers+1D00, strideE8 records. It computes point velocity from current linear/angular velocity and relative position, through `BACC0`; it can continue searching after a match. It must not be replaced with an assumed stationary support.
5. For a nonimmune child with parent body+AA type1, parent definition+1EC bit6 clear returns. Otherwise a second `BB0C0` **replaces** the adjusted scalar with root velocity Z, discarding both preceding adjustments.
6. Require object byte+3DC exactly1. `E4E79..E4E84` computes binary32 `0 - globals[5C]`, then `COMISS` against effective Z; **JBE returns**, so damage/tail admission requires strict ordered greater-than. Equality and unordered values do not admit. There is no impact delta, integrated height, or threshold derived from the labels at globals+08/+0C/+20.

## Authored request, distinct distance-death producer, and delivery

Actual Lockout matg `E1740000` has one 0x68-byte block at file offset 30518876, VA `8014765C`. Both raw tags have definition+14 flags 0. These values are actual cache bytes, not calculated from the schema's distance names. That whole initializer clears 0x88 bytes, writes selected-image material/default operands and three unit-scale fields+54/+58/+5C=1. The caller's pre-initializer word+7C=FFFF is overwritten by the initializer's actual selected material cell. Caller then ORs request+04 with4, writes +84=1, and calls `D7CD0(datum,request+08)`, `RET8`, preserving its real unit/owner-forwarding/team/default-owner alternatives. It invokes **`D9180(request,datum,-1,-1,-1,null)`, RET18**. Node/region/position admission is explicit; there is no ray or collision-hit fabrication.
