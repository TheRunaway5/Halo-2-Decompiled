## Kernel wrapper and error state

`33785C(base,bytes,type,protection)` is four-stack-argument callee cleanup (`RET10`). Its kernel call passes **BaseAddress*, ZeroBits0, RegionSize*, type, protection**, where the two pointers refer to writable copies of its incoming stack arguments. The import cells are TU417C34/u541B6D4, both raw `b8000080` (ordinal184). The resource service owns both updated cells and EAX status. Original `TEST EAX,EAX; JL` accepts every nonnegative status, returning the updated base. A negative status calls2D81D4(status), then forces EAX=0. It does not read last error itself. [Original TU wrapper](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/0033785c-old.asm), [pairedu5 wrapper](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/0033785c-u5.asm).

`2D81D4(status)` (`RET4`) invokes import TU417B70/u541B610, both raw `2d010080` (ordinal301), moves its returned error toEDX, calls2D81A6(error), and returns that error inEAX. The setter (`RET4`) and getter2D817E (plainRET) resolve `TLS = *(FS:[4] + *(487620)*4)` in TU1.1;u5's TLS-index cell is48C920. Setter writes TLS+8; getter returns TLS+8. Both first read FS:24 and conditionally FS:28 before the subsequent TLS lookup. Those source memory dependencies and the status conversion require a real owner; Linux errno is not an inferred Xbox last-error record. [Conversion](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/002d81d4-old.asm), [TLS setter](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/002d81a6-old.asm), [TLS getter](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/002d817e-old.asm), [raw import operands](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/manifest.json).

## Raw producers: alignment and failure are different contracts

`1482A0()` saves/restoresESI, calls33785C with `(0,106470,101000,4)`, and tests the **returned base**, not the status. With a nonzero base, it computes aligned=`(raw+1000)&FFFFF000`, writes105470 at aligned−8 and aligned−raw at aligned−4, then stores aligned in TU480D90/u548605C. It returns the original raw base inEAX, not aligned. Even an already page-aligned raw base advances1000. With base0 it calls2D817E, stores global0 and returns the getter's EAX. Therefore neither a nonzero producer EAX nor a generic boolean can identify its initialized arena; the global store is authoritative. PlainRET consumes no arguments. [TU1482A0](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/001482a0-old.asm), [u5149630](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/001482a0-u5.asm).

`133760()` reserves0x18 local bytes, preservesEBX/ESI, and calls33785C with `(0,452E8,101000,4)`. It saves rawEAX inESI before testing it. Base0 calls the getter **and falls through**: ESI remains0, that value is stored in TU518434/u551DF44, and both1360F0 constructors still run. The second backing argument is reloaded from that global plus22974; neither constructor call applies an alignment operation. The two halves are exactly22974 each. Its plainRET supplies no success flag; finalEAX is the residual constructor result. This does not establish usable renderer storage after failure. [TU133760](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/00133760-old.asm), [u5134B00](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/paired-complete/instructions/00133760-u5.asm).

## Real binding seam and validation limits

The existing `SourceVirtualAllocationRequest/Result` service already expresses base,zero_bits,requested bytes,type,protection,status and updated base/extent. `SourceRuntimeHostStorage` supplies real anonymous host pages in persistent `SourceRuntimeMemory` and reports success after actual allocation; it does not produce Xbox failure status/TLS errors or game fields. A full-ABI33785C binding must preserve both updated caller-stack cells, even though its returned scalar uses only the base. Retained token placement and host page rounding are explicit host adaptation, not recovered Xbox addresses. [Platform contract snapshot](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/native-snapshot/include/halo2/source_static_allocation.hpp), [host allocation snapshot](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/native-snapshot/src/source_runtime_host_storage.cpp), [retained memory](../include/halo2/source_runtime_memory.hpp).

The inspected `source_allocate_static_memory_1_1` snapshot combines11E150 with33785C and already calls last_error on a zero base. Composing it with raw producers that call the getter again duplicates the original call. Parent implementation is splitting33785C from this wrapper and binding1482A0's observed stores; this research does not claim that implementation or its pending comparisons complete. Semantic return domains and full register/stack ABI must remain distinct. Existing full-ABI148190→22E4E0 can consume the retained arena once the real raw producer has run; that stage alone still cannot establish this authored root's complete current-world pressure history. [Combined wrapper snapshot](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/native-snapshot/src/source_static_allocation.cpp), [world ABI contract](../include/halo2/physics_world_runtime.hpp), [prior owning-state boundary](SHIELD_POWER_MODULE_PRESSURE_HANDOFF.md).

The reusable successful-resource oracle is `oracle_mp_biped_component_storage_1_1.py`. At ordinalB8 it reads all five actual kernel arguments, uses real mmap/page-size rounding andmem_map_ptr backing, writes both output cells and advancesESP24 before resuming unchanged instructions. It currently asserts the distinct1409B component request; its fixture results are not runtime inputs for106470 or452E8. It explicitly excludes negative kernel/error branches and whole-map startup. No new original execution was run here. [Existing oracle adapter](../tools/oracle_mp_biped_component_storage_1_1.py), [pinned oracle snapshot](../analysis/damage-shields-goal-20261011/overlay-pass/registration/raw-startup/native-snapshot/tools/oracle_mp_biped_component_storage_1_1.py).
