# Native TU1.5 simple phantom overlap removal

Actual live06 selected owner `315100`, receiver `1007BCC0`, other `1008392C`.
The new 40-site semantic kernel reuses qualified native `314FE0`; the frozen
`315A70` and phantom pair dispatcher sources are unchanged. Both compilers
pass the [38-case model proof](../analysis/physics/native-simple-phantom-overlap-remove-tu15-20261101-qualified/report.json)
and [earlier02 actual-container proof](../analysis/physics/native-simple-phantom-overlap-remove-actual-earlier-tu15-20261101-qualified/report.json).
No actual live06 ENTRY capture or successful visible acceptance is claimed.

This owner searches forward in `phantom+80/+84`, caches the original matching
index and always notifies `314FE0` with its found flag. It performs no other
shape-word read. After notification, a match rereads the current count and
backing pointer, decrements the count and swaps the old last element into the
original matching index. All source read/store order and wrapping arithmetic
remain explicit. Listener callbacks retain the previously qualified typed
RET4 boundary and source-owned nine-byte event; unknown owners must refuse.

The actual earlier02 archive already contains count five and the measured
other at index four, with zero listeners. Original `315100` and native code
both publish count four. Every captured byte plus the nine initialized event
bytes match: 89,795,490 bytes, 16 ordered memory events, five exact stores,
complete FP and actual RET4. No count, capacity or allocation pointer is
changed to prepare the input. Only ordinary receiver/other/FP are marshaled
into an independent new offline control stack. It is not a GP/SIMD postimage
or a reproduction of the production caller's private control frame.

The model covers first/middle/last/missing and empty lists, a null shape word
that must still remove, reverse nullable listeners, direct notify flags zero,
one and FF, 12 read/write fault prefixes, and four callback-return controls
for current count/backing and listener count/backing. All 67 authenticated
sites (40+26+one real no-op) execute. Both compilers match 402 ordered reads,
135 exact stores, 45 genuine callback entries, complete DATA banks and FP;
three semantic mutants are rejected. The
[local input audit](../analysis/physics/native-simple-phantom-overlap-remove-input-context-tu15-20261101-qualified/report.json)
authenticates full zero/all-ones definitions at `31510E` and `31512C`, with
no incoming GP requirement beyond typed receiver/formal DATA and no XMM use.

The first model mistakenly retained both possible private event addresses
for every entry. A direct notify call then exposed an unrelated callback
return-address byte at the unused address. The corrected fixture declares
only the current entry's source-owned nine-byte event before execution,
derived from its authenticated source layout. All persistent DATA comparison
and every current event byte remain strict; the native kernel is unchanged.
The first RED report is preserved. The first actual-input adapter also
retained the old entry jump and correctly failed authenticated metadata lookup;
its corrected ordinary entry is now `315100`, with that RED report preserved.
No byte waiver or manufactured control value is used.
