# First-person sound request production-library registration

The complete upper first-person sound request module is now linked into
`halo2_cache`. CTest `original_first_person_sound_request` runs the unchanged
source-authority test against that actual production archive and the owned
Lockout metadata. Normal and GCC AddressSanitizer/UndefinedBehaviorSanitizer
checks pass, in 0.01 and 0.04 seconds respectively.

The checks compare three authored ready/reload/empty-reload requests, five
event controls, four full marker controls, twelve audibility controls, complete
retained hand stores and the actual imported sound/class records. Their lower
owner inputs and unavailable scheduler replies are explicitly recorded source
leaves. They are not live world transforms, admitted voices or playback.

Source behavior and immutable authority remain in
`MP_FP_SOUND_REQUEST_NATIVE_INTEGRATION.md` and its separately preserved
`MP_FP_SOUND_REQUEST_NATIVE_INTEGRATION_ERRATA.md`. The final source checkpoint
is `e757342c24c736017f5d44dac4148005144266e0bcb81e27309afa8cee89391d`.
The corrected complete comparison contains eleven bodies and 667 instruction
rows per image, 1,334 byte-verified rows across 1.1 and 1.5. Registration does
not alter those source/header/test files or their frozen copies.

The request module and tests compile without original assets. This original
comparison is registered only when the local ignored authority fixture and
owned Lockout cache are present. No game data or comparison fixture is embedded
in the native code.

`MP_SOUND_METADATA_PROVIDER_RESEARCH.md` separately validates the retained
resident metadata providers and imported immutable marker/callback inputs.
The runtime has not installed a first-person event consumer: actual valid
weapon/world/node transforms, location/velocity, listener and camera owners,
source availability/admission/RNG/scheduler/voice lifecycle, and SDL playback
must be completed first. The original failed sound identifier is not replaced
by a successful SDL voice. Reloads are not claimed audible and no new launcher
is published here.

Copied production-test binaries, logs, observed archive hashes, exact source
snapshots and preserved prior pins are frozen in
`analysis/multiplayer/integration/fp-sound-request-production-20261008/frozen/manifest.json`.
