by the object type-dispatch owner: all 13 type addresses and group words,
every inheritance-bank slot through its actual NULL, and each prepare/construct
method identity. The 44 bounded ranges total 480 bytes per selected image.

fixture. Opaque original method addresses still require native callback owners.
