# Original item transform, node, bounds and registry producers

Research date: 2026-10-08. This separate extension executes the unchanged **B8490/B8250/BA1C0/B8320/BD710** paths already admitted by the frozen three-item ordinary/dirty schedule. It measures the real current-node, bounds, location and unsorted-registry producers beneath those paths. Both earlier active and motion runtime sections reproduce exactly. The new observer adds no guest inputs, pose, world record, admission, contact or successful leaf output. [Oracle](../tools/oracle_mp_item_transform_producers_1_1.py), [report](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json), [source audit](../analysis/multiplayer/integration/inventory-source/item-transform-producers/audit.json), [owning motion contract](MP_ITEM_MOTION_BOUNDARIES_RESEARCH.md).

This closes bounded output boundaries for the two moving world items on their original first tick. It does not establish additional frames, continuous settling, a complete frame/session, local device ownership, positive Havok/object/instanced contact, full animated/physical node production or Xbox reciprocal parity. Prior evidence remains immutable. [Inherited scope](MP_ITEM_ACTIVE_SCHEDULE_RESEARCH.md), [player/PVS producer](MP_PLAYER_VISIBILITY_RESEARCH.md).

## Owning transform and dirty order

B8320 snapshots body+4 bit8. When that bit is set and stack8 is false, it first invokes **B96A0**. For an unparented non-NULL point it compares each coordinate against source constants `46594C` and `465490`, then stores root XYZ at **B83B7/B83BC/B83C2** into body+64/+68/+6C. Source orientation stores at **B83F0..B8412** write body+70/+7C when forward is non-NULL. Both actual items have network entity+ D4 NONE, so position/orientation notification B6760 is skipped. [B8320 original bytes](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/000b8320.asm).

The remaining B8320 order is **1C83B0** when stack6 is true → **BDF10** when stack5 is true → **B94F0(datum,location)** when the saved registration bit is set and stack8 false. The actual 1C83B0 executes its physical-component NONE gate; no successful physical update is supplied. Both B8320 calls return **AL1**. B8490 finally calls B8250; its final EAX is the original datum, so its low byte is not an independently defined point-admission result. [Literal before/after buffers and ordered stores](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json), [physical gate](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/001c83b0.asm).

B8250 first tests header+2 bit1 (`02`). All four captured calls take the already-set exit and store nothing. The original positive path writes `02` at **B8288**, then follows body+14 parent until NONE; that path is source-listed only here. [B8250 bytes](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/000b8250.asm).

BD710 executes after the source dirty header test. Both world items have physical component NONE and type2, so it executes **BDF80 → 10CE60 → runtime C0 bit1 from bit2, then clear bit2 → BEDE0 → BFE20 → BF0C0**. The conditional BFE20 is executed because BEDE0 returns AL0 while header40 is set. The C0 stores at **BD7E9/BD7F2/BD7F9** and all no-op stores are retained. Body+10 child NONE skips recursive dirty processing. Both BD710 scopes leave the complete stored item state unchanged, despite executing the producers and callbacks. BD710 does not itself clear header dirty4. ## Source current nodes and bounds

Body descriptors at **+110/+112** identify local node20 storage; **+114/+116** identify current matrix34 storage. Sizes and offsets are actual source-owned words. The BR has no local bank (size 0/offset FFFF); its current bank is four matrices at offset 612 decimal / 264h. SMG has four local records at offset 832 decimal / 340h and four current matrices at offset 612 decimal / 264h. Complete occupied bodies include these banks, and node blocks are additionally labeled by the owning snapshots. [Full node buffers](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json).

BDF80 resolves weapon+38 model, model+4 render model, and render nodes at **+48 count/+4C pointer, stride60h**. Parent, network and physical component are NONE in these world-item paths. BDF80's **BDFD8** clears body+4 bit30. BR bit29 is clear, so **16F3C0** fills the actual global fallback bank `4E38C0` with render-node quaternion at +18, position at +0C and scale `3F800000`. Its C0490 result AL0 skips animation evaluation. SMG bit29 was set by the owning F9EA0 store and its actual local bank exists, so BDF80 uses those source-produced local records without rebuilding an animation pose. [BDF80 instructions](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/000bdf80.asm), [16F3C0 instructions](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/0016f3c0.asm).

BEB30 forms the actual root transform from root/forward/up/scale and source handedness. Actual scale words are **3FD9999A** for BR and **3FC00000** for SMG; parent matrix is NULL. Node0 is converted by **143960 → 1441D0(root,local)**, followed by **10D260**. Nodes1..3 are converted in original index order and composed using each signed render-node parent index at +4. Both actual render tags have parent indices **[-1,0,0,0]**; the nodes are not a sequential parent chain. All four BDF80 calls retain exact node inputs and resulting current matrices; later dirty calls reproduce the already-current matrix bytes. [Source math packets and operand reads](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json).

The 16 executed 143960 calls take the quaternion-length branch containing **1439DF RCPSS**. The capture includes actual length XMM input immediately before RCPSS and actual reciprocal XMM result immediately afterward at **1439E3**, together with subsequent matrix packets and source stores. Original SSE operation order, refinement and signed-zero outputs remain literal. Lazy constants `566760..566767` are captured before/after each producer scope. FPCW/MXCSR are inherited original fixture state, not reset for these calls. Unicorn's reciprocal result is measured evidence; Xbox hardware parity remains unresolved. [143960 unchanged bytes](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/00143960.asm), [math CPU checkpoints](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json).

BEDE0 forms the primary sphere center **body+30** from the first current matrix and definition center+8/+C/+10, with radius **+3C** from body+A0 and definition+4. The alternate sphere at **+50/+5C** consumes definition+20..+2C; definition word+2 bit1000 selects which becomes the registration sphere **+40/+4C**. Registered movement/radius checks use source constant4654C0, can unregister before updating +40/+4C and re-register afterward. In the two transform calls registration was already removed by B8320, so both BEDE0 calls return **AL1** and store the actual sphere buffers. The later two dirty calls return **AL0** without changing bounds. Positive physical bounds service1D7EE0 is unexecuted. [BEDE0 exact arithmetic/stores](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/000bede0.asm), [consumed definition and matrix operands](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json).

The fallback root locator is not used. BR retains literal location **4805000009000000** (leaf1352/cluster9); SMG retains **C30800000F000000**. B94F0 chooses the collidable triplet **4E58B0** from body bit9; **4E58A4** is captured but unused for these two registrations. The owning reverse head is body+60. B96A0 order is **BFE20 → 1CE830 → clear body registration100/header40**. B94F0 order is **location/classification → 1CE650 → set registration100/header40 → BFE20 → B7C50 → B8180**, using the genuine source mask. 1CE650 receives EAX0, actual positive radius, location cluster9/15 and maximum 256. It increments global **4EE9E4**, sets **4EE9E1=1**, executes original **14BD00**, then clears 4EE9E1. The cluster walk uses actual BSP cluster count/pointer at +9C/+A0, B0h cluster stride and +8C portal count/+90 short indices. Portal table is BSP+60, stride24h; portal plane index+4 resolves collision+0C 10h planes. Thirty BR portal tests and four SMG tests execute **14BAC0** in original authored order and all return AL0 at the initial plane-distance rejection **14BB10 → 14BC91**. The sphere/bounding-circle stage14BB16 is never entered. Each sphere therefore produces just its original starting cluster. Positive portal projection/polygon/recursive traversal is source-listed, unexecuted here. Full visited counters/arrays and source plane/portal reads are retained. [14BD00](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/0014bd00.asm), [14BAC0](../analysis/multiplayer/integration/inventory-source/item-transform-producers/instructions/0014bac0.asm), [actual traversal checkpoints](../analysis/multiplayer/integration/inventory-source/item-transform-producers/report.json).

## Native differential and limits

Import each root's complete before-state and actual entry register/stack/pointed buffers. Resolve full datums through the original 12-byte header and body; consume literal weapon/model/render/cache records, original local/current node descriptors, source math constants and existing unsorted pool storage. Execute the source order above, preserving nullable inputs, aliases, no-op stores, full datums, allocator salts and x87/SSE arithmetic order. Compare returned registers/defined AL, complete body/node/header/registry/pool/bitmap/global buffers and ordered stores against the measured after-state. A lower native producer should be compared at its own observed call boundary before replacing the explicit output service in the motion consumer. [Report schema](../analysis/multiplayer/integration/inventory-source/item-transform-producers/schema.json), [independent audit](../tools/oracle_mp_item_transform_producers_audit_1_1.py).
