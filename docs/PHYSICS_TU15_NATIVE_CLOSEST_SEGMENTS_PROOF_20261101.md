compiler and rejects three mutations. The [qualified report](../analysis/physics/native-closest-segments-tu15-20261101-qualified/report.json)
and [aggregate](../analysis/physics/native-closest-segments-tu15-20261101-qualified/aggregate.json)

All 190 authenticated sites become native SSE/x87 arithmetic, scalar clamp
decisions and vector publication. Inputs are two current segment points and
directions, output DATA, nine owned scalar intermediate fields and retained
FP context. The native function returns the actual endpoint-classification
mask. It has no original dependency, GP/SIMD register file, control-frame
serialization, opcode stream or supplied original result.

The physical oracle reaches the genuine helper through the actual Elongation
producer 1 and `30E930` solver, returning normally to `30EAD1`. Cases include
unchanged input, interior crossing, parallel/opposed segments, each endpoint
clamp, both degenerate directions, signaling NaN, output aliasing the second
point, tiny values, FTZ/DAZ and all four rounding modes. Both compilers match
1,426,373,008 persistent bytes, complete output and scalar DATA, typed result
and FP words across 2,505 original instructions and 781 strict ordered
operand events. Result masks 0/1/2/4/5/6/8/9/10 are exercised. Wrong masks,
wrong second-point arithmetic and wrong distance bits are all rejected.

The scalar packet preserves the source's genuine rounding points and exact
operation order, including an extended numerator retained across FST and
comparison, the live first fraction during second classification, source
mask replacement on second-endpoint clamps and recomputation of the first
fraction. The original rereads the second direction/point after publishing
the first point; native code preserves that order so the alias case matches.

For offline operand identity, the scalar packet uses the original owned DATA
area at `alignDown(entryESP-4,16)-0x30`, offsets C through 2C. Only these
source-written numerical fields are passed to the native algorithm. No
saved GP, return address or control lifetime enters that packet interface.
A native caller must supply its own genuine owned scalar DATA area and
preserve any source-required aliases. Normal original ABI is cdecl with five
formal pointer arguments, EAX typed result and RET0; no volatile GP/SIMD
postimages are part of the native function.
