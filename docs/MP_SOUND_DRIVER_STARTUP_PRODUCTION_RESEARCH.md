# Production sound driver startup and immutable operands

The production Cache library includes the frozen complete `source_sound_driver_startup` CPU caller, its cleanup caller and storage owner. `original_sound_driver_startup` matches eight original allocation-prefix cases: 21,968 ordered stores, complete 143,360-byte retained arenas and globals, all four alignment residues, and the exact genuine unavailable device request. The original prefix stops before a device return. The required source helpers and actual device/plugin ownership remain separate as specified in [the driver startup contract](MP_SOUND_DRIVER_STARTUP_NATIVE_INTEGRATION.md).

`OriginalData::sound_driver_startup_operands` has a separate `SoundDriverStartupImmutableOperands` type with only the original one word and two 12-byte basis vectors. Both actual forwarding pointers are checked before dereferencing their whole payloads. It cannot hold the startup caller's mutable routing plugin identity. That plugin (`486590→48B8A0`), runtime environment packet (`477548→47C77C`), saved audio setting, device identity/capabilities, DSP residency and stream ownership require their actual lifecycles.

Independent authenticated exports match (`operands.tsv` SHA-256 `6db2cf67150fed2e04bcf1e13c035059a68ad6905219a22383716f1ded24ce63`; report `1a8389ef04d4389ee66a0dde5a8d685909fdb5734e4b5bfaa895cdc48f886804`). `original_sound_driver_startup_operands` verifies all 56 imported immutable bytes across verified 1.1/u5 images and confirms that the unverified base-image provider stays absent. Production GCC normal and ASan/UBSan runs pass both registered tests. The original differential's mmap-backed test is registered on UNIX; the startup CPU implementation itself contains no OS-specific calls.

Build records retain the initial missing-target-before-configuration failure and the local operand variable-name compile collision, followed by corrected builds and passing checks. No original fixture expectation or platform return was changed to pass them. These results establish the registered CPU prefix and immutable operands. They do not establish successful driver initialization, saved output-policy restoration, DSP/plugin adaptation, source voice admission, audible reload playback or all-map sound effects. The canonical launcher is unchanged.
