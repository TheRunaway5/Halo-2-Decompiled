## E6050 motion and animation branches

`E6050` uses ECX=unit, EAX=optional vector pointer, stack `{root_arg2,root_arg4}`, `RET 8`. Unit BYTE`+3DC==3` bypasses its initial motion/body branch. Otherwise a root object with no parent and an actual true `E5680` result calls `BB0C0` with EAX=unit, ECX=its local output vector, stack `{0}`. It dots that actual vector with the source up vector and retains the original SSE comparisons and definition scalar calculations before optional `BACC0`/`B8490` displacement. It then calls `E6DC0`. With a nonzero optional vector pointer and non-NONE arg2 it stores arg2 to unit`+450`, current tick to`+44C`, and the three vector DWORDs to`+454`. Nonzero arg4 additionally invokes original `110BF0`, `1D1940`, and the literal animation component flag/byte resets. [Complete E6050](../analysis/damage-shields-goal-20261011/live-fatal-cleanup/research/lowers/instructions/000e6050-old.asm).

`BB0C0 → BC200` is107 instructions, EAX=unit, ECX=optional first output vector, stack `{optional second output vector}`, `RET 4`. It walks actual parent`+14` identities to the root, obtains actual physical-component datum`+B4`, and validates the signed BYTE component`+18` against body count`+74`. With a valid body and root BYTE`+C1` bit0 set it copies the original zero vector. Otherwise it invokes the appropriate call-free vector owner with EAX=body index, EDX=physical component, ECX=output: `1D43C0 → 1D8C80` or `1D44C0 → 1D8D80`. Those resolve component`+70`, stride`60`, rigid-body pointer`+40`; a nonzero rigid-body`+40` uses zero, otherwise the motion object behind rigid-body`+3C` supplies its vector`+40` or`+50`. When there is no valid physical body, `BB0C0` copies root object vectors`+88`/`+94`. It allocates no new physics state.
