The new native module closes the complete direct `1CEC20` request body and general `1CEE00` channel installer. Its measured type0 path executes the existing complete `1DEB60` lookup, resource demand, variant selection, channel installation and frame clamp against the same retained buffers. It supplies no successful lower result. This is a constructor dependency closure, not a live grenade or full Unit integration claim.

The separate evidence directory is `analysis/multiplayer/integration/spawn-source/unit-channel-request`. Previous constructor, request/resource, variant, transition, grenade, audio and release freezes remain immutable. Production changes are limited to the new header/source/test and their CMake registration; Unit, Simulation, runtime, frontend, renderer and shaders are untouched.

## Exact direct contract

`update_source_unit_channel_request` takes actual writable manager90 and channel32 spans, class/weapon identifiers and `SourceUnitChannelRequestServices`. Channel can alias a manager channel, an original extension channel or separate source scratch storage. Tests preserve each actual alias and compare the complete unit body where captured. No allocation or component offset is performed by this function.

The body returns defined AL false immediately when channel graphDWORD0 isNONE or packed highword+6 isFFFF, without reset or graph lookup. Otherwise it resolves manager+68 through the real graph provider, captures incoming packedDWORD+4/activityDWORD+8/typebyte+E, and substitutes manager+74/+78 only for literal `07000101` current sentinels. Mode is manager+70.

The actual six-DWORD jump table at `1CED84` is:

| Signed channel typebyte | Required branch |
| --- | --- |
|0 | complete`1DEB60`, optional resolved pointersNULL |
|1 | required complete`1DF670` provider |
|2,3 | reset |
|4 | graph+3C bank, activity key, stride28h |
|5 | graph+44 bank, activity key, stride14h |
|negative or >5 | reset |

The byte is sign-extended and checked with unsignedJA; negative values reach reset. A found row supplies packedDWORD+4. Packed highwordFFFF resets. An equal valid packed value returns true with no channel store. A changed valid value invokes general`1CEE00` with the original activity, flags re-read from channel+12 **after lookup**, first/second bytesFF and the original captured typebyte. This preserves mutations by real lower owners. Failed installation resets and returns false.

Reset preserves all bytes outside its exact14 stores, in order: graphNONE32, packedlowFFFF16, packedhighFFFF16, framezero32 at+1C, bytes+10/+11 zero, words+12/+14/+16 zero, imported one32 at+18, activityNONE32 at+8, bytes+C/+D FF, word+E FFFF. Instruction identities and full before/after values are retained by the observer.

`install_source_unit_requested_channel` implements complete general`1CEE00`. Manager graphNONE returns false before lower work. Flagsbit10h requires the complete caller-owned variant/RNG/resource owner; it then re-reads manager graph and executes complete`1C9E60`. Only an admitted install runs flagsbit4 frame clamp at literal zero. Flagsbit8 subsequently writes imported one to channel+18. The function returns the source defined AL. It accepts full incoming flag/byte words; the existing installer preserves source byte/sign-extension widths. There is no default packed animation, clamped duration, unchanged-variant fallback or audio/world success.

## Remaining live owners

This module can satisfy the real `1CEC20` call once an owning caller provides its exact retained manager/channel spans and required metadata/RNG/resource/clock services. It does not construct nativeUnit storage or turn Q into gameplay.

The immediate complete caller `114F00` remains a separately required owner: it indexes the original header by low16, resolves the actual body, sign-extends body+12A/+33E, then calls this request owner for extension+9C, +DC, +BC, in that order. The first two pass current sentinels; the third passes class`0400054B` and extension+98 weapon. The original constructor fixture calls it once with sourceNONE extension channels; it does not prove an admitted live request. No production header, body or component offset is supplied to bypass that caller.

Type1`1DF670` remains an explicit mandatory alternate-lookup callback; this new native module does not implement it. Types4/5 and reset type cases are complete-body/table-backed branches but have no new positive caller fixture here. Other required owners remain `1CFA90`/resource/current-transform sweep, `114BD0` and its lower pose/aim owners, complete native body/type allocation and constructor composition, live resource/RNG/clock initialization, and grenade dispatcher/begin/attachment/release/projectile/fuse/explosion/authority. These cannot be replaced with successful defaults or a final body copied from the fixture.
