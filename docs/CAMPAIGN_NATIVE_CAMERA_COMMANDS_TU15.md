It contains no virtual CPU, instruction loop, private guest stack, captured result, original-code execution or lifted callback.

Each original persistent store remains individually observable. None of these owners touches x87; live x87 values/control/status are preserved. The qualified profile has masked SIMD exceptions and supports rounding, DAZ/FTZ, existing sticky status and NaNs. Unmasked SIMD traps remain an explicit platform boundary.
