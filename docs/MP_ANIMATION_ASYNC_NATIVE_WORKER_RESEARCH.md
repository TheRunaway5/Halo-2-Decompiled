The new composition matches **32 ordered original stores**, every retained queue/current/done/count byte and the complete `0x50000`-byte IO buffer. Normal and GCC ASan/UBSan checks pass. Evidence lives under `analysis/multiplayer/integration/spawn-source/animation-async-native-worker`. Its report and fixture independently reproduce byte for byte. The earlier [constructor](MP_ANIMATION_ASYNC_CONSTRUCTION_RESEARCH.md) and [worker/file](MP_ANIMATION_ASYNC_WORKER_RESEARCH.md) freezes remain unchanged. ## Actual request, IO and retirement

The main thread submits `SourceBitmapReadRequest { location=00BB4800, size=0x7A00, buffer=82947000, bytes_output=0A103010, done=0A103000, category=7, priority=3 }`. The size/location come from the earlier actual Lockout resource-request capture; callback destination addresses and poison/count inputs remain explicit bounded fixture inputs. The native file bank maps token `F4000001` to the actual read-only Lockout path. These are retained host tokens, not recovered original file-open output.

The complete `19D8C0/1A4870` owners lease, fill and publish the real node. The actual semaphore wakes the worker; it captures the published node under the work mutex, stores the current-node pointer and calls TU `1A47D0` outside both list mutexes. The verified `SourceAsyncOwnedFiles` backend performs the real seek/read. It reads exactly 31,232 bytes at file offset `00BB4800`, SHA-256 `0332fd04ccaa80d41f0fc5a1a6e997942264db867b92ff98b19901908926aa3d`. Source task/count stores and terminal result 1 follow those genuine file outcomes. Source writes done, unlinks and returns the node to the free list in the original order. No callback result, IO count, done byte or loaded flag is manufactured.

A separate host promise observes release after free-list retirement. It is not a source/game completion field. The main thread then requests stop and joins the actual worker. The cancellable wait adapter checks stop before acquiring a real permit; it throws before source post-wait writes. Real finite polling timeouts stay inside that adapter. The immortal source worker never receives a fabricated timeout, failure or acquired return to make it exit. The captured native outcome must be `Stopped`; actual worker failures are rethrown.

## Concurrency and integration limits

This case has one request and one worker. Main never polls raw done/cache/IO bytes concurrently. Publication uses the actual source mutex/semaphore; the worker exclusively owns the task after publication. All complete-buffer checks occur after real stop/join. List access uses its actual source mutex. Thus ordinary raw-byte callbacks are safe for this **quiescent ownership composition**. The result does not establish a portable concurrently polled cache-memory ABI. A live overlapping cache reader needs a synchronized memory owner/read/write interface or explicit atomic completion visibility; a mutable span alone is insufficient.

The implementation seam is the unchanged `SourceAnimationAsyncWorkerServices`: bind actual waits/releases, retain the memory/file owners, and run `run_source_animation_async_worker` inside a retained `NativeThreads` task. Bind `read_source_animation_async_file` only to genuine owned path/token/buffer records, and invoke `submit_source_animation_async_read` for the original publication path. Alias values are explicit native namespaces. Missing providers still stop; no successful defaults were added.

Original `19D820/19DAD0/19EE30/1A4250` path/open/token production remains unported here. Source TLS/SEH/error/NTSTATUS, priority and requested-stack translation remain separate boundaries. The earlier full u5 mappings remain static evidence; this new runtime case executes TU1.1 only. Resource residency/active consumers, current transforms, complete Unit construction and live Q are still separate owners. No runtime, Unit, renderer, shader, release or GPU changes are made. The only CMake change registers the new focused test.

Exact commands, snapshots, dependency pins, diagnostics and a read-only audit are in this scope's `REPRODUCE.md` and `manifest.json`. The early unsupported Unicorn subclass attempt is preserved under `drafts`; the corrected wrapper changes only host root invocation, not guest code or state.
