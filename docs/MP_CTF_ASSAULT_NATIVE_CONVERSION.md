# CTF/Assault semantic native conversion

Xbox TU1.5 is the gameplay authority. The scope is all nine authored presets,
their original option consumers, and the complete shared mode-specific closure.
Prepared MCC data remains content; original executable bytes are offline reference
inputs. Each semantic owner retains its literal implementation for traced and
same-binary differential controls. No executable payload is added to the game.
